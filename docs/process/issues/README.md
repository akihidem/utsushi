# 閉じた Issue の記録

2026-11-06 の本人の指示で、開いていた Issue（この repo の 75 本）を 11-07 までに閉じた。指示の言葉:「提出を止める物は直して閉じ、それ以外は中身を記録（決定・process の文書）に残したうえで閉じる」。

Issue を閉じても、中身と残った事はここから読める。1 本ごとに次の 5 つを書く。

| 項目 | 中身 |
|---|---|
| 番号と題 | GitHub の Issue への link |
| 中身 | 何が問題か・何を望んだか |
| 決まった事 | 決まった事と出所（決定の記録 J・[decided-and-open.md](../decided-and-open.md) の本人の決定・PR・commit） |
| やった事 | 入った PR・commit |
| 残った事 | まだの事と、誰が決めるか・いつか（本人・実物の試行・提出の後 など） |

## 読み方の決まり

- 残った事のある Issue も閉じた。未決の正本は [decided-and-open.md](../decided-and-open.md) の「まだ決まっていないこと」で、U 番号の Issue はそこに移した行から辿れる。
- 動いている仕事（デモの撮影・提出の残り・本物の API の試験）は、[../../progress.md](../../progress.md) と [demo-notes.md](../demo-notes.md) を生きた記録にする。
- 記録はまとめた時の物で、新しい決定は作っていない。記録と決定の記録が食い違う時は決定の記録が正。
- この記録の文は Claude Code のセッションが Issue と PR から書き、文書だけの差なので統括のセッションが読んでから入れた（別の系統の目は通していない）。
