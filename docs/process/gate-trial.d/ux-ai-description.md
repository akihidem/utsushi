## 頁の head に description と og の字を足す（AI に読みやすく・(2)、サイトの線、ux/ai-description、11-08）

- 目的: AI と検索が、頁を開く前に中身を読めるようにする。頁の見た目は変えない
- なぜか: 本人の言葉（11-08）「リードミーも他の部分もも、審査員も見るけど、AIも見る。まずはAIフレンドリーに。して。1番初めに言ったけど、AIにも選んでもらいたい。」。統括の決め（11-08）: 今ある字で合う物が無い頁の description は空ける（新しい字を作らない）。順は (2) description → (4) SVG の名 → (1) /llms.txt → (3) docs の入口
- どうしたか: skin.meta_head（description・og:title・og:description）を足し、skin.shell と入口の play_server.page から呼ぶ。description は頁にもう出ている字の全体だけ（入口と序は S1・保護者の方へは 1 節の 1 行目・作った物は頭の説明の文・改善の一周は頭の文・組み立ての頁はその頁の頭の文（立体で組める玩具は LEAD・組めない玩具は STEPS_LEAD）・英語の入口は POSITION）。ギャラリーの頭の文は、字を変えずに定数 GALLERY_LEAD へ移し、頁と description が同じ物を引く
- 字の全体にした訳: 訳の表（web.i18n）は content の属性も鍵で訳すので、頁の字と同じ鍵で英語とやさしい日本語になる。入口の副題は 3 つの字に分かれていて、つなぐと訳の表に無い字になるので使わなかった
- 空けた頁: 玩具の頁・手帖・手帖の記録の頁・作りながら見る頁・英語の玩具の頁・くずし字の頁・図鑑の本の頁・作る側の頁・断りの頁ほか（今ある字で頁の中身を言う 1 文が無い）
- 比べた案: 頁ごとに説明の文を新しく書く（新しい字になり、本人の確かめが要る。統括の決めで作らない）
- 本人の決めとの照らし: 本人「まずはAIフレンドリーに」直った（7 頁）・一部（空けた頁が残る）。J-015「読み手の AI への指示は書かない」直った（今ある字だけで、頼みの字の形も試験で見る）。S1 を頭へ（入れる）直った（入口と序の description。入口の見える所には足さない・本人の決めで入口の題の間は題・副題・道だけ）
- ゴールの要件: description は決めた今ある字と一字も同じで、その字は頁に出ている。og:title は <title> と同じ。空けた頁には出さない。英語では日本語の字が残らない
