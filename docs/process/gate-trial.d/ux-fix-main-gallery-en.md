## main の作例の節の試験と訳の表の重なりの直し（UX の担当、ux/fix-main-gallery-en、11-08）

- 目的: #553（審査用の頁）が main に入ると、作例の節（/gallery）に報告の 4 回の段（web.kaizen_ws.workshops() の回ごとの 1 行・日付で始まる）が出て、tests/test_sakurei_gallery.py の「日ごとの見出しが残った」と「回の一覧が無いのに報告の段が出た」と「型紙の版は 1 つ」と英語の見張りに当たった（main 62bce810 で rc 1）。あわせて、窓口の直接合体の重なりで data/i18n/en.json に同じ鍵が 2 つずつ並び、test_en_all の重なりの見張りが落ちた
- どうしたか: ①試験: 本人の言葉「日毎にはしない」は札の並べ方（日ごとの見出し）の事で、報告の段は別の設計なので、日付の字と型紙の版の数は報告の段を除いた札の側で見る。日付の見出し（h2〜h4 の頭の日付）が無い事を足した。報告の段は「回の一覧の口があるか」と「段が出るか」が合う事を見る形にした（#553 の前の木でも後の木でも通る）②訳の表: 作例の節の報告の段の 1 行（「日付　何をしたか」が 1 つの字の節）の鍵 3 つと、直った所の行 2 つの英語を足した（英語は審査用の頁の同じ字の英語をつないだ）③訳の表の重なり 3 つ（「うつしは、学校や博物館などで…」「{0} 月 {1} 日から…」と、#597 の後に増えた「人」）は値が同じなので、後に並んだ方を外した
- 弱める向きでない: 日ごとの見出しの線は札の側でそのまま見て、日付の見出しの線を足した。報告の段の線は「口が無ければ出ない」を「口と段が合う」に広げた（口が無い時は前と同じ見方）
- 検証ゲート: **済み**。Red: main 62bce810 に新しい試験だけを置くと test_sakurei_gallery rc 1（報告の段の英語）・test_en_all rc 1（重なり）（gate-evidence/red-gallery-report-en.txt・red-en-dup-main.txt）。Green: green-gallery-report-en.txt・green-en-dup-main.txt
