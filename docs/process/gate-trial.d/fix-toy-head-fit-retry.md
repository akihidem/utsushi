## 玩具の頁の頭の重なりの試験で、Chrome が答えなかった束を回し直し、それでも答えなければ落とす（README の担当、fix/toy-head-fit-retry、11-08）

- 目的: 別の目の気づき（統括を通して 11-08）。tests/test_toy_head_fit.py が負荷の高い時に毎回 83 頁の束が 1 つ「Chrome が答えなかった」で測れずに rc 0 で通る
- なぜか: 束（1 つの言葉と 1 つの大きさの 83 頁）を 4 つの Chrome で同時に回し、答えが揃わなかった束は「測れない所あり」と出して通していた。混んだ機械で測ると、測れなかった束は 2 つ（1 つを落とした時）・8 つ（1 つを毎回落とした時）あった
- どうしたか: 答えが揃った束だけを見る。揃わなかった束は 1 つずつ（同時に回すと混んだ機械でまた答えない）2 回まで回し直し、揃った時に見る（同じ頁を 2 度数えない）。回し直しても揃わなかった束が残れば落とす（測れない頁を通さない）。Chrome が無い機械は前のまま測れないと出して通す
- 比べた案: 時間切れを延ばすだけの案は、混んだ機械では答えない束が残るので採らない
- ゴールの要件: 決めた束（ja-1024x768）の Chrome の答えを落とす見張り（repo の外・/tmp/fitdrop/drop.py。subprocess.run を差し替える）で、1 度だけ落とすと試験が rc 0 で測れなかった束 0、毎回落とすと試験が落ちる
- 検証ゲート: **済み**。Red: main（07471476）の試験で、1 度だけ落とすと rc 0 で測れなかった束 2（gate-evidence/red-head-fit-retry-once.txt）、毎回落としても rc 0 で測れなかった束 8（red-head-fit-retry-always.txt）。Green: 1 度だけ落とすと rc 0・回し直した束 1・測れなかった束 0（green-head-fit-retry-once.txt）、毎回落とすと試験が rc 1（green-head-fit-retry-always.txt）
- 限り: 回し直す分だけ、混んだ機械では試験の時間が延びる（1 つの束で 1〜2 分）
