## 頭の帯の駅の間に、流れの印（→）を置く（直しの担当、issue/nav-arrow、11-07。夕方のレビューの 11）

- 目的: 頭の帯で、えらぶ → つくる → のこす → もちよる と進む向きを読めるようにする
- なぜか: 夕方のレビュー（11-07・朝の版を見た人）の 11「えらぶ の後は つくる、つくる の後は のこす、と流れが分かるように明示」。帯は駅の名が並ぶだけだった。仕分け（窓口の指示「決まりとぶつかる物だけ本人へ」）で、駅の名と並びを替えず間に印を足すだけなら決まりとぶつからない、とされた
- どうしたらいいか（比べた案と推し）:
  - 推し: 駅と駅の間にだけ印（ROAD_ARROW）を置く。読み上げない飾り（aria-hidden）で、押す所にしない。よむ・English の前と英語の頁の帯には置かない
  - 比べた案: 駅の名の前に番号（1 えらぶ・2 つくる…）を付ける。駅の名の字が変わり、本人の決定（11-06）の字とぶつかるので採らない
- 足した決め: 帯の段を増やさないよう、印の左右を詰める（広い幅 -8px・幅 480 以下 -4px）。詰めないと幅 320 で 2 段に折れる見積もりだった。印の字は 1 か所（skin.ROAD_ARROW）で、形は窓口の確かめ
- ゴールの要件: 6 つの頁で、帯の並びが うつし・えらぶ・印・つくる・印・のこす・印・もちよる・よむ・English。印は 3 つでリンクの外。英語の頁の帯に印が無い。幅 320 と 390 で 1 段に収まる（見積もり）
- 検証ゲート: **済み**。Red: 今の main（`f46a5c2a`）にこの試験だけを置くと、並びに印が無く rc 1（gate-evidence/red-nav-arrow.txt）。Green: この枝で rc 0（gate-evidence/green-nav-arrow.txt）
- エビデンスゲート: 手元の Chrome で /gallery を幅 320 と 390 で撮り、駅の列が 1 段に収まるのを目で見た
- 確かめていない事: 本物のスマホと iPad での見え方。読み上げの道具で、駅の名だけが続けて読まれる事
