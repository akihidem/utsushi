## 玩具の頁の足の前と次と一覧の道を外し、作りながら見る頁の畳みの道を国立国会図書館へそろえる（Issue 対応の担当、issue/toy-foot-off、11-08）

- 目的: 玩具の頁（つくる）の直しのうち、#595・#596 の後に本人の確かめが要った 3 つを、本人の答えのとおりにする
- なぜか: 本人の答え（11-08・統括を通して）「つくるの頁の一番下の前と次のおもちゃと一覧への道は外す」「スマホは絵と狂歌を縦に積む形でこの形でよい」「作りながら見る頁の大きく見るも国会図書館への道にそろえる」。元の言葉は 11-08 の「大きく見る、図を見る、は統一して国会図書館へのリンクへ。…ほかのおもちゃ、のリンク要らない。」
- どうしたらいいか: 玩具の頁の足の道（toy.neighbours）から、前と次の玩具への道と「おもちゃの一覧」（/toys）を外した（toy.foot_links）。作った物と入口への道は答えに無いので残した。作りながら見る頁の原画と歌の畳み（genga.fold）は、「大きく見る」と頁の中に重ねる窓（dialog と JS）を外し、玩具の頁の頭と同じ 図を見る（国立国会図書館）の 1 つの道にした。絵そのものも同じ所へ行く。どちらも別のタブで開く（作りながら見る頁は頁を離れると声の聞き取りと鏡が止まる。前の「頁を離れない」の理由をこの形で残した）。畳みの「原文の引用。確かめた人」の行も外した（11-08 の最初の言葉「原文の引用確かめた人要らない」を、頭とそろえた。答えの 3 つに無い所なので、統括へ断って出す）。狭い幅は替えていない
- 見た事: 足の道を外すと toy.py で sources が使われなくなったので import から外した。図鑑の本の頁（/zukan/hon/<n>）の「大きく見る」は本の頁の絵の写しを開く物で、本人の答えの「作りながら見る頁」に入らないので残した。手帖の作る頁（techo_step）の小さな原画の釦は字の無い押す所で、「大きく見る」の字は無いので替えていない
- ゴールの要件: `tests/test_toy_foot_ndl.py`（足に前と次と一覧の道が無い・作った物と入口は残る・出典は頁の一番下のまま・狭い幅の並びは今のまま・畳みに大きく見ると重ねる窓が無い・道は国立国会図書館のその絵の頁へ別のタブで・畳みに確かめた人の行が無い）
