## やさしい日本語の手帖と作りながら見る頁で、ルビのある字の行の間を広げる（直しの担当、fix/easy-ruby-gap、11-08 昼）

- 目的: 字の重なりの見回り（tests/test_no_overlap.py・#684）の (5)。やさしい日本語では全部の漢字にルビが付く。手帖（最初の画面・手順の画面）と作りながら見る頁で、次の行のルビ（rt）が前の行の字に重なっていた（手順の字の「物差（ものさ）し」の下の行の「たし」、外筒の「やまお」、返事の断りの「れんらくさき」「えいぞう」、鏡の断りの「かがみ」など）
- 原因: 行の高さが、ルビの無い字に合わせた値のままだった。手帖の手順の字 1.4（32px で 44.8px）・断り 1.7、作りながら見る頁の今の手順 1.45・返事の断り 1.6（体の 1.6 を受け継ぐ）。ルビは字の上に字の半分の大きさで載るので、1.4〜1.7 では前の行の字の箱に 2〜13px 入った
- どうしたか: ルビは やさしい日本語 の時だけ出る（日本語と英語の頁には ruby が無い・手帖・作りながら見る頁・くずし字・入口・よむ で数えた）ので、`:has(ruby)` で やさしい日本語 の時だけ行の間を広げた。手帖は `#steps li` と `.meta` を 1.9、作りながら見る頁は `#steps li` と `.meta` を 1.9、JS のある時の今の手順を 1.85 にし、その字の大きさの下限を 24px から 22px に下げた（上限 44px と幅の 3.6vw は同じ）。日本語と英語の頁の見た目は替わらない
- 比べた値: 1.9・2.0・2.1 を Chrome で当て、どれも手帖と作りながら見る頁のルビの重なりが消えた（鏡の断りの span だけは親の .meta に当てた時に消える）。行が高くなる分を小さくするため 1.9 にした。作りながら見る頁の今の手順は、1.9 のまま 24px だと 375×667 の虎の最後の手順で字が 4 行・34px 伸び、手順の紙の絵が下限（120px）まで縮んでも のこす の札の下の端が画面の下の端まで 8px を割った（tests/test_tsukuru_last_fit.py rc 1・665px）。1.6・1.7・1.75 はルビが前の行の字の箱に 3〜11px 入って残った。22px・1.85 で字は 3 行（122px・前の 1.45 の時は 148px）になり、ルビは重ならず、のこす の札は前と同じ所。作りながら見る頁の 3D の段の注（12px・1.4）は重なりが 2px で、試験の線（3px）の下なので替えていない
- 検証ゲート: **済み**。Red: 直す前の木（#684 の頭 f5f6547c）で、KNOWN からルビの決まりを外した試験が rc 1（`docs/process/gate-evidence/red-easy-ruby-gap.txt`）。Green: 直した木（写しあり）で tests/test_no_overlap.py rc 0（`green-easy-ruby-gap.txt`）。test_tsukuru_last_fit（下の端までの余裕 10〜116px）・test_landscape_fit・test_easy_all・test_easy_ruby・test_sheet_window・test_tap_size・test_hmd・test_techo_step・test_easy_svg_text rc 0
