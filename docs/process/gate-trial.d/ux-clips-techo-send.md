## 手帖の最後の「のこす」と、作りながら見る頁の「のこす」の道でも、声とカメラの区切りを届ける（UX の担当、ux/clips-techo-send、11-08）

- 目的: #655 の別の目の気づき（#640 の形）と統括の決め 11-08。手帖から作業の頁へ行って録った区切りは、作業の頁の「のこす」から移った時しか渡らず、手帖の最後の「のこす」で終えると送られなかった（本人の「解析につかう」に外れる）。作りながら見る頁の最後の「のこす」（#643・フォームで送って のこす の頁へ着く）でも、渡す押しが無いので、のこすの頁を開いた時に消えた
- どうしたか:
  - web/clips.py に送るだけの小さな台本（SEND_SCRIPT・録る code なし）を足し、手帖の作る頁に置いた。手帖の「のこす」で記録を作った直後（その場限りの印を作り直す前）に、同じ玩具・同じ画面・今の回の区切りを、その記録の写真の口へ見出し X-Utsushi-Clip で送り、送れた物を消し、回と印を消す。送れなかった時は、のこすの頁と同じ決めた 1 行
  - web/nokosu.py: のこすの頁を開いた時は、今の回のまだ渡していない区切りを渡してから並べる（回の印で前の人の物とは分かれる）
- 幅 390 の頭なしの Chromium で通した: 玩具の頁 → 作業の頁で録る → 手帖の最後の画面で「のこす」→ 結果の札 → 置き場に voice/t1.mka ができた（R-0001）／玩具の頁 → 作業の頁で録る → 作りながら見る頁の最後の「のこす」→ のこすの頁の確かめの並びに区切りが並んだ
