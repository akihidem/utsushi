## 頭の帯の「うつし」を釦でない題の字にし、入口へ行く釦を えらぶ の 1 つにする（Issue 対応の担当、issue/nav-one-door、11-07）

- 目的: 頭の帯に、同じ所（入口 /）へ行く釦が 2 つ並ばないようにする（#522 の上）
- なぜか: 入口が えらぶ になり、帯の「うつし」（入口への道）と「えらぶ」が同じ所へ行く釦の対になった（本人のサイト体験レビュー 11-07 の 3「同じ物が何回も出る」）。窓口の決め（11-07）「頭の帯の重なり: 行き先が同じ釦は 1 つにそろえる。帯の並び（うつし｜えらぶ つくる のこす もちよる｜よむ）は決めたまま」。今夜の締めの延長で、提出の後へ回していた物を出す（統括 11-07）
- どうしたらいいか: `skin.nav` の「うつし」を `<span class="brand">` にした（字と並びはそのまま。見た目の決まりは .nav .brand なので変わらない）。英語の帯は同じ所へ行く対が無いので触らない。比べた案: 「えらぶ」の方を外す（決めた帯の並びが崩れるので採らない）
- 見た事: #548 の後の main の test_nav_arrow が帯の項目を `<a>` と駅の札だけで数えていたので、題の字（span.brand）も並びの中の字として数える形にした（並びの期待は替えていない）
