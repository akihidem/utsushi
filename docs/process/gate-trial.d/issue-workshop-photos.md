## 玩具の頁の「これまでの記録」に、ワークショップで作られた物の写真を出す（直しの担当、issue/workshop-photos、11-07 夜）

- 目的: 本人の言葉（11-07 夜・統括を通して）「おもちゃ毎のつくるにあるこれまでの記録にはワークショップで作られた写真を載せて欲しい」
- どうしたか: repo の試行の写真（docs/process/trials/photos の 11-04 の 9 枚と 11-06 の 34 枚）を、各日の確かめ表の「写っている物」と 11-06 の答えの作ったおもちゃの名で照らし、写真 → 玩具の印の表（data/workshop_photos.json・照らした理由つき）にした。表に入れたのは 15 枚（御来迎 11・張子の首振り虎 1・風車 3）。「と読める」の弱い読みと、写りから玩具が決まらない写真は入れず、一覧を統括へ返した（本人の確かめに回す）。玩具の頁の「これまでの記録」の頭に、その玩具の写真の小さい写しを並べる（web.workshop）。字は前からある alt「作った物の写真」だけで、人の書いた感想は出さない。合言葉なしの公開の場にも出す（本人の直の指示・写真は公開の決めが済んだ物）
- 比べた案: 写真を作例の記録（web.sakurei・via=workshop）として取り込む形。作例の受け口は写真の元を repo に入れない作りで、repo に在る試行の写真を記録の置き場へ写すと同じ写真が 2 か所になるので、表で指す形にした
- ゴールの要件: `tests/test_workshop_photos.py`（表の写真が在る・玩具は 83 の中・その玩具の頁に、その玩具の写真だけが表の順で出る・写真の無い玩具は並びを出さない・小さい写しは 100KB 以下・表の外の道は 404・公開の場も同じ）
- 検証ゲート: **済み**。Red: 今の main（288930ae）に試験と表と web.workshop だけを置いた木で rc 1（並びが無い。`docs/process/gate-evidence/red-workshop-photos.txt`）。Green: rc 0（`green-workshop-photos.txt`）
- 確かめていない事: 風車は答えの名「風車」で照らした（諫鼓鶏の風車でない事は写真では確かめていない）。
