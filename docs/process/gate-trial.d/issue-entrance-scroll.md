## 入口の題の間から「まずはここから」へ送る仕掛けと、注記の 1 文を外す（直しの担当、issue/entrance-scroll、11-08 朝）

- 目的: 本人の言葉（11-08）「サイト、。新しい絵は作っていない。はトル。トップページスクロールしてもらう仕掛けを。うつしの文字や周囲のひろい領域タップしてもスライドしても下にスクロールしおもちゃを選ばせる、切り抜きした4つのおもちゃをタップしてもスクロールして2つのおもちゃを選ばせる。」
- どうしたか: 設計（別の直しの担当が書いた grove の state/entrance-scroll-design-20261108.md）のとおり、web.looks に送る台本（DOWN_JS）と字の無い下向きの印（DOWN）を足した。題の間の click（浮かぶ玩具は pointer-events:none のままで、押すと題の間に当たる）と上へ 30px 以上のスライドで、まずはここから へ滑らかに送る。動きを減らす設定では飛ぶ。送った後は まずはここから（tabindex=-1）に focus。押せる所（帯・このサイトについて・言葉の切り替え）は今のまま。注記 3 か所の「新しい絵は作っていない。」を外し、英語とやさしい日本語の表の鍵を替えた
- 設計から替えた所: 印の置き場を「題の間の下の真ん中」から「最初の画面の右下に留める（fixed）・40px 送ったら消す」にした。題の間は画面いっぱい（100svh）で頭の帯の分だけ画面の下へはみ出し、題の間の下に置くと最初の画面に入らなかった（幅 390×844 で印が 921〜969px）。真ん中は幅 390×844 で「このサイトについて」（790〜834px）と重なるので右下にした。送った後の focus の枠が節の全体を囲んで見えたので、節の focus の枠は消した（2 枚の札の枠は残る）
- ゴールの要件: `tests/test_entrance_scroll.py`（白と暗い版: 注記の字が頁と表に無い・新しい鍵がある・題の間に字の無い印 a.tj-down（href="#mazu"・読み上げ「まずはここから」）・まずはここから に tabindex=-1・台本が click と touchend で送り、押せる所を除き、動きを減らす設定で smooth と auto を分け、focus を置き、印を留めて消す・見えた時に起こす仕掛けを使わない・浮かぶ玩具はリンクにしない）
