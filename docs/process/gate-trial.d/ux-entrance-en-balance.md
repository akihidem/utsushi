## 入口の横書きと読みを英語の頁だけにし、iPhone の幅で左右の真ん中にそろえ、読みを大きめにする（README の担当、ux/entrance-en-balance、11-08）

- 目的: 本人の言葉（11-08・#644 の続き）「英語は英語モードの時のみ横書きで、他はかえない。iPhoneで見ると英語モードの左右のバランスがズレてる。Utsushiはすこし大きめのほうがいい。」
- なぜか: #644 は読み utsushi を日本語とやさしい日本語の頁にも出し、狭い幅の日本語の頁の上の余白を 24px 詰めていた。英語の頁の真ん中に寄せた字は、字の間（letter-spacing）が最後の字の後にも付くので、字の間の半分だけ左へずれて見えた（題のひらがなは .6em で、幅 320 の時 左 56px・右 83px）
- どうしたか: 日本語とやさしい日本語の頁は #644 の前の形に戻した（読みは出さない・上の余白は詰めない。字の形は頁の作りが 1 つなので残る）。英語の頁の真ん中に寄せる字（題のひらがな・読み・英字・副題）は、左に字の間と同じ余白を置いて、字の見える所を真ん中にした。読みは 20〜28px（副題は 14〜17px）・字の色を副題と同じ濃さにした
- 比べた案: 字の間を 0 にして真ん中にそろえる案は、題の字の並びの見た目（余白維持）が替わるので採らない。測る時の 15px のずれ（スクロールの帯の分）は iPhone では起きないので、画面の幅はスクロールの帯を除いて測る
- ゴールの要件: tests/test_entrance_yomi.py（白と暗い版・日本語・やさしい日本語・英語・幅 320/375/390/430/1440: 日本語の頁は読み無しで縦書き・英語は横書きで副題は 1 つの句・読みはひらがなの下で副題の 1.25 倍以上・真ん中に寄せる字の左右の余白の差が 4px 以内・重ならない・はみ出さない・幅 390×844 と 1440×900 で このサイトについて が最初の画面の中）
- 検証ゲート: **済み**。Red: 今の main の形で rc 1（gate-evidence/red-entrance-en-only.txt・日本語の頁に読み）、真ん中の余白を外すと rc 1（red-entrance-en-center.txt・題のひらがなが左 56px・右 83px）。Green: rc 0（green-entrance-en-balance.txt）
- エビデンスゲート: 入口・英語・やさしい日本語の関わる試験 15 本が rc 0。日本語の頁の このサイトについて は幅 390×844 で 834px（#644 の前と同じ）。幅 390 と 430 の英語の頁の絵を白と暗い版で目で見た
