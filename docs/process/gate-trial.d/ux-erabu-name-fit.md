## えらぶの棚の名の札を、折らずに 1 行で切る（隠れた行とルビの覗きを無くす）（README の担当、ux/erabu-name-fit、11-08）

- 目的: 本人の言葉（11-08）「iPadで横表示で見たら文字が重なってる。PC、iPhoneなどいろんな大きさで見ても崩れないようにして。」。字の重なりの見回り（grove の state/no-overlap-20261108.md）の 4「えらぶの棚で、英語とやさしい日本語の玩具の名が札の絵に重なる」
- なぜか: 札ごとに名の字の箱・札の箱・絵の箱を並べて測った（11-08・幅 390・1440・375・本物の原画の写し）
  - 札の箱は、英語でもやさしい日本語でも絵に重ならない
  - 重なりとして数えられたのは、行の数の切り（-webkit-line-clamp:1）と overflow:hidden で隠れた 2 行目からの字の箱だった。長い名は 2〜25 行に折れ、隠れたまま札の下（次の絵と下の道の所）に並ぶ。見回りの測り方は、字の親の要素そのものの切り口では切らない
  - 目で見える崩れは 1 つ。やさしい日本語で、隠れた 2 行目のルビの頭が名の下に覗いた（幅 390 で撮って見た）
  - 日本語でも幅 375 では長い名が 2 行に折れ、隠れた行があった
- どうしたか: skin.BASE の .narabi .nm を、折らずに末を … で切る形にした（white-space:nowrap・text-overflow:ellipsis。入口の全部の玩具の並び .tj-narabi .nm と同じ形）。隠れた行が無くなる
  - ルビは行の箱（19.2px）を広げずに上へ 4px はみ出し、札の箱の上の端で切れた。札の上の間 6px を、外の余白 1px と内側の余白 5px に分けた。内側 2px と 3px では 1px 切れた（落ちた版: gate-evidence/green-erabu-names.txt・-2）。名の位置は替わらない
- 比べた案: 名を全部折って見せる案（行の数の切りを外す）は、頁が長くなる（toys.py の注の 3 列・名前 1 行の決め）ので採らない
- ゴールの要件: tests/test_erabu_names.py（新・白と暗い版・日本語・やさしい日本語・英語・12 の大きさで、名の字は 1 行・ルビは札の箱の中・札の箱は絵と下の道とほかの札に重ならない・札は列の幅の中）
- 検証ゲート: **済み**。Red: main（4ba66d26）で rc 1（gate-evidence/red-erabu-names.txt・日本語 375×667 で長い名が 2 行以上）。Green: rc 0（gate-evidence/green-erabu-names-3.txt・今の main に載せ直して green-erabu-names-4.txt）
- エビデンスゲート: えらぶと棚に関わる試験（test_toys・test_toys_genre・test_erabu_fold・test_tap_size ほか）rc 0。test_toy_foot_ndl は 4ba66d26 の木では直しの前から落ち、今の main（58c449da）では通る
- 字の重なりの見回りの試験（state/no-overlap-20261108.md の tests/test_no_overlap.py）への気づき: 字の箱を、字の親の要素の overflow でも切らないと、隠れた字（行の数の切り・… で切った末）を重なりとして数える。この直しの後も、… で切った末の字の箱は横へはみ出して数えられる見込み
- 限り: iPhone の Safari と iPad の実機では見ていない。長い名は末が … で切れる（全部の名は玩具の頁で読める）
