### 別の目の止め 3 つと気づきの直し（11-08・統括の決め）
- 止め 1: README の話す口の行を「Claude には送らない」に（README では「AI」でなく「Claude」と書く決まり・test_readme_head）
- 止め 2: 作業の頁の手順の画面に長い断り（初めて録る時の 1 行・端末の置き場の 1 行）を置かず、カメラの断りの 1 行と、保護者の方への頁（前からある名）と のこす への道だけにした。端末の置き場の 1 行は のこすの確かめの画面に出す
- 止め 3: 作り始め（手帖の「はじめる」・作業の頁を開いた時）に、その玩具の印の無い区切りを消し、次に渡す時は新しい印にする。作業の頁を のこす の頁から戻って開いた時は作り始めとしない。手帖の作る頁は録らない決まりなので、消しだけの小さな台本（clips.START_SCRIPT）を置く
- 気づき: 印は玩具ごと（utsushi-pass:<印>）で、3 時間の内の今の印を使い直す（戻って録り足しても前に渡した区切りが消えない）。承認の終わりの消しはその玩具だけ。置き場の断りに本人の答えの字「このサイトをほかの画面で開くと、前に録った声と映像は消えます。」の 1 句。frames の置き場は共用の /tmp でなく記録の置き場の下の mkdtemp（0700）
- 幅 390 の Chromium で 4 つの形を通した: 前の人が録っただけで去る → 次の人が作業の頁を開くと消える／次の人が渡すと自分の区切りだけ／のこす から戻って録り足して渡すと 2 つとも並ぶ／前の人が のこす を開いて承認せずに去った後に、次の人が作業の頁から始めて渡すと、前の人の物は並ばない
- 残る穴: ブラウザの戻る釦で頁が読み直されずに作業の頁へ戻った時は、作り始めの見分けが効かない
- 検証ゲート: Green は gate-evidence/green-voice-camera-client-fix.txt
- 残る穴の直し（統括 11-08）: 戻る釦で頁が読み直されずに作業の頁へ戻った時（pageshow の persisted）も、前の頁がどこでも作り始めとする。同じ人が のこす から戻る釦で戻った時は、前に渡した区切りが次に渡す時に並ばなくなるが、前の人の声を次の人に送らない方を採った。この Chromium（頭なし）では戻る釦で頁が読み直され（bfcache に入らず）、読み直しの形で作り始めが効いて、前の人の物が並ばない事を見た。bfcache から戻る形は、まだ実機で見ていない

### 回の印（11-08・統括の決め・別の目の残る道と逆向きの気づき）
- 作り始めは「玩具の頁を開いた時（のこす から戻った時を除く）」。その時に回の印（utsushi-run:<印>）を新しく作り、印の無い区切りを消し、次は新しい渡す印。作業の頁と手帖の「はじめる」は、同じ玩具の回が 3 時間の内なら引き継ぐ（無い時だけ作り始め）。区切りに回の印を付け、渡す印は今の回の物にだけ付ける。頁の種類は頁の側が言う（玩具の頁の考えを話す節と作業の頁の台本が openedAs を呼ぶ）
- 幅 390 の頭なしの Chromium で通した形:
  - 前の人が玩具の頁で話して去り、次の人も玩具の頁で話して直に のこす へ → ["p2-toypage"]
  - 前の人が作業の頁で録っただけで去り、次の人が玩具の頁 → 作業の頁で録って のこす へ → ["p2-voice"]
  - 前の人が のこす を開いて承認せずに去り、次の人が玩具の頁 → 作業の頁で録って のこす へ → ["p2-work"]
  - 同じ人が玩具の頁で話す → 作業の頁で録る → のこす → ["mine-toy","mine-work"]（逆向きの気づきの直し）
  - 同じ人が のこす → 作業の頁（リンク）→ 録り足す → のこす → ["mine-toy","mine-work","mine-more"]
