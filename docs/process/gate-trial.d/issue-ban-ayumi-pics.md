## 型紙の版の歩みの額に、repo の中から作れる版の絵を出す（直しの担当、issue/ban-ayumi-pics、11-07 夜）

- 目的: 玩具の頁の「型紙の版の歩み」の額に、版ごとの型紙の小さな絵を出す。作れない版は、空の額でなく「この版の絵は残っていない」と出す
- なぜか: 本人の見直し（11-07 22:16）「過去の版が表示されていない。」。額の絵は repo の外の置き場（out/history/sheets。エンジンが組ごとに出した絵を写す所）にだけあり、repo の clone で動く公開の場では全部の額が空だった
- どうしたらいいか（比べた案と推し）:
  - 推し: 置き場に無い絵は、repo の中から作れる版だけ作る。改善の輪より前の版（御来迎 v1〜v10・虎 v1〜v3）は、刷って渡した紙の PDF（docs/process/trials/sheets の仮説 A。v1〜v4 は仮説 A に当たる tab）の 1 枚目。今の版（御来迎 v14・虎 v7）は、今の雛形でたたき台を刷った 1 枚目。作れない間の版（御来迎 v11〜v13・虎 v4〜v6）は字で残っていないと出す
  - 比べた案 1: エンジンが出した 21 枚の絵（repo の外の置き場）を小さくして repo に入れる。生成物を repo に入れない決まり（画像は NDL と東京学芸大学の PDM の物だけ）に当たるので採らない
  - 比べた案 2: 間の版も、今の雛形かエンジンの見本（examples）で刷り直す。その版の時のコードではないので、その版の紙として見せる事になり、採らない。この repo の履歴でも、御来迎は v10 から v14 へ飛び（v11〜v13 は来ていない）、虎の v5 も来ていない
- 確かめた事: 改善の輪より前の版の PDF の 1 枚目は、エンジンが出した絵と同じ紙（縮めた絵の差の平均が 1 未満。ほかの仮説の紙とは 3 以上）。御来迎 v14 の今の雛形の紙も、エンジンが出した v14 と同じ形（差 1.9）。虎 v7 は、エンジンが出した絵（11-07 10:36）と今の雛形の紙で題と並びが違う（今の雛形の紙を出す）
- ゴールの要件: 作れる版は img で、絵は幅 298 の PNG。作れない版は「この版の絵は残っていない」の字で、空の額は出さない。頁を返す時は絵を作らない（作るのは絵が求められた時）
- 検証ゲート: **済み**。Red: 今の main（654256ed）に tests/test_ban_ayumi.py だけを置くと、虎の額の絵が v7 だけで rc 1（gate-evidence/red-ban-ayumi-pics.txt）。Green: この枝で rc 0（green-ban-ayumi-pics.txt）
- エビデンスゲート: 手元の Chrome（幅 1280・置き場の空のサーバ）で、御来迎は 11 の額に絵・3 つに字、虎は 4 つに絵・3 つに字。字は語の切れ目で 2 行に分かれる（word-break: auto-phrase）。全頁の英語の表に 1 行
- 確かめていない事: 「この版の絵は残っていない」の字は本人の確かめ待ち。公開の場（トンネルの先）で、最初に開いた時の絵の作りの遅さ（手元では 1 枚 0.06 秒、今の版は 0.9 秒）
