# 関門の試行の帳面の節（1 枝 1 ファイル）

- 11-07 から、新しい節はこの置き場に、枝ごとに 1 ファイルで書く。ファイルの名は「枝の名.md」（枝の名の / は - に替える。例: 枝 fix/gate-trial-d は [fix-gate-trial-d.md](fix-gate-trial-d.md)）
- なぜ: 前はどの枝も gate-trial.md の終わりに節を足したので、1 本が main に入るたびに、列に並ぶほかの PR が GitHub で衝突した（GitHub は帳面の `merge=union` を使わない。11-07 に開いていた 21 本のうち 17 本）。枝ごとに別のファイルなら、足す所が重ならない
- 書き方は前と同じ: 1 件 1 節（`## ` の見出し）で、目的・なぜか・どうしたか・ゴールの要件・検証ゲート・エビデンスゲート・マージ後の書き戻し。帳面の決まりと前の節は [gate-trial.md](../gate-trial.md)（前の節はそのまま残る）
- 同じ枝で直しを重ねた時は、同じファイルの節を書き足す（ファイルを増やさない）
- `tests/test_gate_trial_merge.py` が、gate-trial.md とこの置き場の節を同じ検査で読む（見出しが重ならない・衝突の印が無い・検証ゲートの行がある）
