## 作業しながら見る（試作）の頁で、カメラの映像の上に今の手順の 3D を半透明で重ね、指で合わせる（A 重ねる）（直しの担当、issue/kasane-overlay、11-08）

- 目的: /toy/<印>/kasane（カメラに重ねる）と /toy/<印>/kasane/hmd（HMD）で、今の手順の 3D を実物の上に重ね、指で位置・大きさ・向きを合わせる
- なぜか: 本人の言葉（11-08）「A → B → C の順。」の A。作業の頁の前提（11-07）「HMD か iPhone カメラでオーバーレイする形での作業を前提に、作業ページを作ろう。」と「AI が 3D で表示して中身をそこで分解できる構造表示と、自分が作った実物がオーバーレイする。」。設計は grove の state/kasane-a-design-20261108.md、別の目の確かめは state/kasane-a-design-review-20261108.md、統括の決め ①〜③（HMD の道も最初から重ねる・4 隅の印は外す・重ねている間は 3D の見る向きの回しを止める）
- どうしたらいいか（比べた案と推し）:
  - 推し: 描き方は kumitate の CSS の立体のまま、舞台（.rt-stage）を頁の置き場に置いたまま transform（置き場からのずれ・大きさ・向き）で合わせる。半透明（0.6）・層は 映像 → 3D → 字と押す所。1 本指で動かし、2 本指の長さの比で大きさ・角の差で向き・真ん中で位置。Safari の gesturechange も同じ所へ（2 本の指が来ている時は使わない）。鍵 + − [ ] 0。「元に戻す」は重ねている間だけ押す所に出す
  - 比べた案 1: 舞台を画面に固定（position:fixed）して動かす（設計の時の形・前の 4 隅の印の形）。頁の流れから外れるので、字が長い手順で押す所が画面の下へ押し出された（横 1280×720・縦 500×701 の試験で落ちた）。採らない
  - 比べた案 2: 「元に戻す」を頭の帯に置く。帯が折れて 2 行になり、横の画面で 3D が見える高さを超えた。統括の決めで、押す所の列に置き、横で高さの低い画面だけ 2 列にした
  - 比べた案 3: 4 隅の印を残す。4 つで 8 回触るより 1〜2 本の指で合い、向きも合わせられるので外した
- ゴールの要件: カメラを付けるまで重ねない（HMD の道は最初から）。重ねると 3D は半透明で、層の順は 映像 → 3D → 字と押す所。指と鍵で合わせた値が替わり、重ねている間は 3D の見る向きが替わらない。元に戻す で重ね始めた所へ戻る。カメラを止めると重ねをやめて既定へ戻す。カメラが使えない機械でも 3D は出る。重ねている間、頁は網に何も送らない。横 1024×600 でも重ねている間の押す所（7 つ）が全部見える
