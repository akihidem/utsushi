- 目的: 本人の答え（11-07 夕・夕方のレビューの Q2）「組み方は 3D を基本として文字で見る。図は要らない」。夕方のサイトのレビューの 13「手帖にも組み立て図が残っているのでやめる」。UX の担当の仕分けの PR-E（手帖の分。組み方の節は別の PR-F）
