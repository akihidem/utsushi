## 上げた動画の声を、この機械の中で字にしてから消す（声の線、voice/keep-voice-text、11-08。J-022 の決め直し）

- 目的: 本人の言葉（11-08）「全部残していいことにしたい。」・（11-07）「ルール変える必要ある。音声は文字化してから落とさないと価値が減る」。手帖に上げた動画の声を捨てずに字にし、字にしたら元の音を消す。字にできなければ 72 時間で消す（本人の決め 11-08）
- なぜか: 前は、手帖に上げた動画の音を受けた時に字にせずに捨てていた（`techo_site.clean_video`）。動画の専用の口（#388）は既に字にしてから消す形だった
- どうしたらいいか: 推しは、動画の専用の口と同じ順（声を非公開で写す → 手元で字にする → 字を書いたら消す）を、字にする所と掃除をまとめた部品（`omochae.voice_text`）で、両方の口が使う形。比べた代案: 受けた時にその場で字にする（返事が数十秒遅れ、上げた人を待たせる）／外のサービスで字にする（声を外へ出す。本人の決めが要る）。設計は grove の state に置き、別の目を通した
- 足した決め（別の目の指摘から）: AI にコマを見せる口と束が字を読まない／字に名乗りと連絡先と学校の名の床を通して伏せる／字にする道具の無い機械でも 72 時間の掃除を回す／公開の場の大きさの合計に声も数える／2 つの口の名（voice/voice.mka と voice/m<n>.mka）を両方扱い、2 度字にしない
- 子どもの声: 決まり（今週は成人のみ・子どもの写真と声は扱わない）は変えない。上げる所と保護者の頁に「子どもの声は入れないでください。」を足した（本人の確かめ待ち）。今ある動画は、本人の確認で子どもがいない
- ゴールの要件: 字にする前に声が消えない／字にした後は声が残らない／字に名乗りと連絡先が残らない／72 時間を過ぎた字の無い声は道具の無い機械でも消え、印が残る／頁・束・AI に見せる口に字が出ない／取り下げで消える／頁に出す動画に音が無い（今のまま）
