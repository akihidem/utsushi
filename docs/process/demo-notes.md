## 台本の案（作る側、11-04。本人が採るか直す）

- **なぜか**: 審査は repo と動画だけを見る（提出の要項）。本人が渡した参考の 3 つ（作り方を作品の形で見せる、数字と工程を出す、道具のクレジットを出す）を当てはめる

- **ゴールの要件**: 3 分以内（提出の床が動画の長さを測る）。人の顔と声が入らない。画面の数字はどれも repo の記録と合う（下の「出す数」の出所）。最後に repo の名とクレジット
