# J-009 手順の紙と記録の入口

- **状態**: 決定。実際の人が使った確認はまだ

## 手順の紙

| 案 | 判断 | 理由 |
|---|---|---|
| 計算の開く角度の見込みを刷る | 捨てた | 予想と測った数を比べる時に答えを先に言う事になる。虎の周期の見込みは、虎を作る時に改めて考える |
| 組み方を 1 つの文章にまとめる | 捨てた | 押し方で工程が違う。溝の無い形に溝の手順を出さないよう、寸法の組から生成する |
| 工程ごとの小さな図を付ける | 今は 1 枚の見取り図だけ | 実物を組むと直す所が多いと見込む。組めた後に足す |

数の予想の欄を「作る前に」に置いた。正解は刷らない。

## 記録

- 結果は「動いた／動かない／わからない」の 3 値が必須で、既定は無い。集計は別々に数え、合算しない。
- 直した点は部品名・変えた事・結果の 3 欄が揃った物だけ残す。
- 開いた力（紙の力・糸・手）を記録する。Q1 と H-A〜H-D を比べるため。
- 仮説は実在の ID だけ。自分の仮説（OWN-n）も引ける。
- 成否を写真から判定しない。写真の欄はまだ無い。

## まだ無い物

記録の解釈の案、次の版の差分案、次の仮説の提案、順位を人が更新する操作（どれも輪の後半で、未実装）。一覧には記録の数だけを見せ、順位は変えない。
