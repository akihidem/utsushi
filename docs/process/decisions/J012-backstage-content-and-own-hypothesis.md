## 考え方

その場で文や図が出てくる事自体は、もう珍しくない。この作品で価値があるのは、内容が確かな事と、試した記録で次が変わる事。その場の速さは、学ぶ人が待たずに済む所でだけ要る。

| | 前（J-011） | 今 |
|---|---|---|
| 内容の本体 | 使う時に Claude が作る | 裏で時間をかけて作り、確かめた物を配る |
| その場で動く所 | 仮説の生成全体 | 学ぶ人が自分の仮説を立てた時に、それを型紙に変える所だけ |
| 見せ方 | 生成の瞬間 | 内容の確かさと、記録が次を変える輪 |
| 固定の仮説 | 受け皿 | 裏の制作の成果物そのものの置き場 |

## 裏の制作と検証の仕組み（案）

```
図・歌・複写との照合・前例
  → Claude が仮説・寸法・手順の案を作る（J-011 の生成の道具を流用）
  → 決定的な検査（寸法・印・式の向き）
  → 別の Claude が固定の観点で読む（作った者と別の目）
  → 人が確かめる
  → 実物で試す
  → 記録で直す
```

`data/hypotheses` の各仮説に、どこまで確かめたかを持たせる。

| 段 | 意味 | 確かめる者 |
|---|---|---|
| 案 | Claude が書いただけ | — |
| 検査済み | 決定的な検査を通った | 機械 |
| 別の目を通過 | 別の Claude が根拠と断定を読んだ | Claude |
| 人が確認 | 人が読み、根拠を確かめた | 人 |
| 実物で試した | 紙で作って試した記録がある | 人の手 |

**正直に書く所**: Claude は紙が開くかを確かめられない。「確かさ」の最後の段は人の手で、Claude をいくら回しても埋まらない。今ある 8 つの仮説は「検査済み」までで、「実物で試した」は 0 件。

## 自分の仮説を型紙にする口（その場で動く唯一の所）

今の `own` は、型紙にするのに寸法の JSON が要り、学ぶ人には使えない。ここを次の形にする。

```
自分の言葉の仮説（動かし方・図のどこを見たか）
  → Claude が雛形と寸法に写す（読みを足さない。判定もしない）
  → 決定的な検査 → 描画器が紙を描く
  → 雛形に乗らなければ「型紙にできない。どの部分が乗らないか」を返す
```

守る線: 学ぶ人の仮説を直したり、正しさを評価したりしない。写せない所を勝手に補わず、補った寸法は紙に書く前に見せる。鍵が無い時は、雛形の選択と簡単な欄から作れる形を受け皿にする（今の JSON を人の言葉の欄に直す）。
