# J-035 全頁を英語で読めるようにする（出口で訳の表を引く形）

- **状態**: 本人の言葉（2026-11-07、窓口を通して届いた）と、窓口の決め 130735（案 B）。
- **本人の言葉**: 「サイトは全てのページを英語で読めるようにする。全頁が対象です」
- **問い**: J-030 は「頁を丸ごと 2 言語にしない。入口（/en）と玩具の頁（/en/toy/<id>）だけを足す」と決めていた。本人の言葉はこれを替える。どの形で全頁を英語にするか。

## 決めた事

- 頁ごとに英語の頁を書かない。サーバが返す HTML の見える字を、訳の表（data/i18n/en.json）で英語に置き換える（web/i18n.py）。頁を作る部品は日本語のまま作る。
- 英語にするのは cookie の lang=en の時だけ。頭の帯の右の端の English（前は /en へ飛んだ）が、今の頁の英語へ切り替える（?lang=en）。英語の頁では同じ所が「日本語」に替わる。道は日本語の頁と同じ。
- 前からの英語の頁（/en と /en/toy/<id>、web/en.py）は替えずに残す。そこにある本人が採った英文（PREMISE・INTRO・POSITION・ENGINE）は一字も替えない。
- 訳は作る側（Claude）の下書きで、英語の頁の頭に下書きの札（en.DRAFT、本人が採った字）を 1 つ出す。
- 人が書いた記録・感想・寄せられた声は訳さない（機械で訳した他人の言葉を出さない）。本人の言葉の引用は、日本語の原文を残して英訳を添える。昔の狂歌の行は日本語のまま。
- 型紙の PDF は日本語のまま（凍結の床を替えない。J-030 と同じ）。
- 訳し漏れは試験（tests/test_en_all.py）が止める。全部の頁の道を回し、表に無い日本語の字が 1 つでもあれば落ちる。

## 測った数

- 11-07 の main（62dd1119）で、全 83 種の玩具の頁（玩具の頁・組み立て・作りながら見る・手帖・重ねる・図鑑・くずし字・作る側の頁）と玩具に依らない頁の 830 の道を回すと、見える日本語の字は 2570 種（69,618 字）。訳は 6 つに分けて並べて作った（作る側の下書き）。
- 頁を英語に替える時間は、御来迎の玩具の頁（664KB）で 14ms → 68ms（手元で 1 回）。

## 残した事（まだ英語にならない所）

- 台本（<script>）が後から出す字（聞いた返事・知らせの一部・数え方の字）。台本の字を置き換えると動きを壊しうるので、触っていない。
- POST の後の知らせで、試験の道に出ない物。表に無ければ日本語のまま出る（試験が拾えない）。
- 英語を母語とする人の確かめ。

## 前の決定との関係

- J-030 の「頁を丸ごと 2 言語にしない」を、本人の言葉で替えた。J-030 の方針 3（型紙は正解でなく仮説・紙で動いても昔の証明にならない、を落とさない）と方針 7（記録と写真は国ごとの同意の形を決めてから）は残る。英語の頁でも記録の口は日本語の頁と同じ物で、同意の文も同じ文の英訳。
