# J-002 動く仕組みを 1 つに決めず、複数の仮説として並べる

- **状態**: 決定（本人の指摘による組み直し）
- **経緯**: 最初の版は「つまみを既定にする」と決めていた。扇の軸も既定にした（J-005）。本人に「何通りか仮定を提案するんじゃなかったっけ」と指摘された。その通りで、既定を選ぶのは作品の本筋と逆だった。

## なぜ既定が間違いだったか

- この作品の中心は、絵と歌から立てた仮説を、作って試して見分ける事にある。作者が 1 つ選ぶと、答えを配る工作の道具になる。
- 証拠は割れている。絵の側面の棒、博物館の記事の「つまみを押し上げる」、『還魂紙料』を引く解説の「筒を下げる」は、同じ動きを示していない。
- 一番絵に近く見える案も、実物では試していない。

## 変えた事

| 前 | 今 |
|---|---|
| 既定はつまみ。ほかは切り替え | `data/hypotheses/` に仮説 5 つを並べ、順位を持たない |
| すぐ型紙を刷れる | 予想を書かないと一覧も型紙も出ない（F9.prediction） |
| 型紙は 1 つの案を示す | 紙に「試すための 1 つの翻案。答えではない」と刷り、題に仮説の名を入れる |
| 計算で落ちた案は消える方向 | 計算で不利な案も根拠と弱い所を付けて残す（H-E） |

## 並べた仮説

| ID | 仮説 | 主な根拠 | 確かさ |
|---|---|---|---|
| H-A | 側面のつまみで押し上げる | 絵の側面の棒、博物館の記事 | 観察・二次資料 |
| H-B | 内筒を下から押し上げる | 行程の計算 | 計算 |
| H-C | 柄を下から押し上げる | 藁の束に刺して売ったという解説 | 解釈 |
| H-D | 柄を持って筒を下げる | 『還魂紙料』を引く解説 | 二次資料（原典は未確認） |
| H-E | 扇を筒の口の台に載せる | 作りやすい。ただし計算では半円まで | 計算 |

開く力（紙の力・糸・手）は、仮説とは別の問いとして残す。H-A〜H-D の型紙に糸の穴を刷るので、1 個で比べられる。

## 輪とのつながり

予想 → 仮説を並べる → 人が 1 つ選ぶ → 刷る → 作る → 記録 → 順位が変わる。順位を変えるのは試した記録だけで、記録の根拠 ID が要る（F4）。Claude が仮説を立てる段ができたら、この一覧に足す形にする。今の 5 つは Claude Code のセッションが書いた案で、人の確認はまだ。

## 残る検討

- 5 つは多すぎるかもしれない。使い手の負担は実際に通して確かめる。
- 仮説どうしを 1 回の試作で見分けられるか（H-C と H-D は同じ型紙で見分けられる）。
