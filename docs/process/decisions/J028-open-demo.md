# J-028 デモの 2 サイトを、合言葉なしで他の人も見られる形に開く

- **状態**: 本人の許可（2026-11-05 朝、窓口を通して届いた）
- **本人の言葉**: 「デモサイト 2 つを他の人でも見れるように公開していいよ」
- **窓口の補足**: 白の展示と黒のジンのデモを、他の人が見られる形に開く。合言葉の門は外す方向で。開いたら、渡せるリンクを窓口へ返す

## 開き方

- 起動の台本に、合言葉なしで開く形を足した（`run-demo.sh` の open の指定）。白と黒の 2 サーバ・2 トンネルは同じ。
- 前の決定（11-04、合言葉付きのリンクで 3 台が開ける形）は、合言葉付きの形として残す。同時には立てない。

## 開いた場で守る線

| 線 | どうしたか | なぜ |
|---|---|---|
| 写真と動画 | 受けない（受け口が断る。手帖の上げる口を閉じる）。置き場に在っても出さない | 誰でも上げられる場では、確かめていない写真（顔・他人の物）がそのまま皆に見える。持ち寄りは同意と権利を確かめてから載せる線（J-021）と、子どもの写真を扱わない線を守る |
| 前の記録 | 開いた場の置き場は別（合言葉付きの時の記録と写真を、開いた場に出さない） | 合言葉付きの場で書いた人は、皆に見せる前提で書いていない |
| 字の記録 | 残せる（予想・試した記録・感想・説明・聞いた事）。連絡先の形は床で落とす。記録の欄と聞く口に「名前は書かないでください」 | 一周できる事がデモの芯。名前は機械で落とせないので、断りで頼む |
| AI | デモの置き場には鍵を置いていないので、聞く口はよくある言葉の答えだけ | 開いた場から費用のかかる呼び出しをさせない |
| 別の出所 | 書き込みは同じ出所の頁からだけ（今までどおり） | よそのサイトから書かせない |

## 確かめていない事・決まっていない点

- 開いている間に書かれた字の見回り（誰が・どの間隔で読むか）。不適切な文が書かれた時に消す手順は、置き場のファイルを消す手作業。
- 開いておく期間。トンネルの名前は立て直すたびに変わる。
- 人が多く来た時の重さ（1 台の機械で 2 サーバ）。
