# J-028 デモの 2 サイトを、合言葉なしで他の人も見られる形に開く

- **状態**: 本人の許可（2026-11-05 朝、窓口を通して届いた）
- **本人の言葉**: 「デモサイト 2 つを他の人でも見れるように公開していいよ」
- **窓口の補足**: 白の展示と黒のジンのデモを、他の人が見られる形に開く。合言葉の門は外す方向で。開いたら、渡せるリンクを窓口へ返す

## 開き方

- 起動の台本に、合言葉なしで開く形を足した（`run-demo.sh` の open の指定）。白と黒の 2 サーバ・2 トンネルは同じ。
- 前の決定（11-04、合言葉付きのリンクで 3 台が開ける形）は、合言葉付きの形として残す。同時には立てない。

## 開いた場で守る線

| 線 | どうしたか | なぜ |
|---|---|---|
| 写真と動画 | 受けない（受け口が断る。手帖の上げる口を閉じる）。置き場に在っても出さない | 誰でも上げられる場では、確かめていない写真（顔・他人の物）がそのまま皆に見える。持ち寄りは同意と権利を確かめてから載せる線（J-021）と、子どもの写真を扱わない線を守る |
| 前の記録 | 開いた場の置き場は別（合言葉付きの時の記録と写真を、開いた場に出さない） | 合言葉付きの場で書いた人は、皆に見せる前提で書いていない |
| 字の記録 | 残せる（試した記録・感想・説明・聞いた事）。他の人の頁には出さない（#242 のギャラリーの時に決めた）。連絡先の形は床で落とす。記録の欄と聞く口に「名前は書かないでください」 | 一周できる事がデモの芯。名前は機械で落とせないので、断りで頼む |
| AI | 鍵（.env）のある所では開かない（立てる時に断る）。AI の口も閉じる。聞く口はよくある言葉の答えだけ | 開いた場から費用のかかる呼び出しをさせない |
| 作る側の頁 | /loop と玩具ごとの様子の頁を出さない | 聞いた言葉と感想の文がそのまま読める頁で、名前は機械では落とせない |
| 次の版を採る口 | 閉じる | 誰でも型紙の版を変えられる形にしない |
| 自分の仮説 | 文を頁と図鑑に出さない。文が刷られる紙も開かない（#336・#402）。頁の書く口は合言葉付きの場でも閉じた（#332） | 人ごとに分かれておらず、文の中の名前は機械で落とせない |
| 別の出所 | 書き込みは同じ出所の頁からだけ（今までどおり） | よそのサイトから書かせない |
| 内部の番号と作る側の控え | 記録の番号、閉じた口への案内、読みと観察の文、頁の注釈を出さない（11-06 の点検） | 読む人に要らない。作る側の控えと内部の名前を、誰でも読める形にしない |

## 確かめていない事・決まっていない点

- 今のデモは合言葉付きのリンクで渡している（hack-main の判断。門を外すと、リンクを知らない機械も書き込める）。合言葉なしの形は、本人が門そのものを外すと決めた時に使う。
- 予想の門は玩具ごとで、人ごとではない。1 人が予想を書くと、ほかの人にも仮説が開き、その人の文が「あなたの予想」に出る（合言葉付きの共有でも同じ。Issue に分けた）。（追記 11-05: 予想の段は #242 で外したので、この問題は無くなった）

- 開いている間に書かれた字の見回り（誰が・どの間隔で読むか）。不適切な文が書かれた時に消す手順は、置き場のファイルを消す手作業。
- 開いておく期間。トンネルの名前は立て直すたびに変わる。
- 人が多く来た時の重さ（1 台の機械で 2 サーバ）。
