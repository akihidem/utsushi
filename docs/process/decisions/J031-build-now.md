# J-031 予想の段を無くし、開いたらすぐ作る形にする。他の人の作った物のギャラリーを作る

- **状態**: 本人の決定（2026-11-05 昼、窓口を通して届いた。窓口のカード 20261105-122840 への答え）
- **本人の言葉**:

> 予想の段を無くして、すぐ作る形にする

> 他の人の作ったものギャラリーは作る

引用の外は書き手（Claude Code のセッション）の整理で、本人の言葉ではない。作りの変更は Issue #242 で進める。作りは枝 lane/build-now で入れた（門・予想の欄・タップの形を外し、ギャラリーを足した）。

## きっかけ

本人の許可（11-05）で、デモのリンクを他の人に渡した。予想の門は玩具ごとで、人ごとではない。そこで次の事が起きる（Issue #208。手元で cookie の無い別の人を装って再現した）。

- 人 A が予想を書くと、人 B の画面に、人 A の文が「あなたの予想」の見出しで出る
- 人 B は、自分の予想を書かなくても、仮説と型紙が開く

## 比べた案と、捨てた理由

窓口に出した案は 3 つで、本人はどれも採らず、予想の段そのものを無くすと決めた。

| 案 | 中身 | 結果 |
|---|---|---|
| 見出しだけ直す | 「あなたの予想」を「これまでの予想」にする | 採らない。段を無くすので要らなくなる |
| 人ごとに分ける | 無作為の印を cookie で持ち、門と「あなたの予想」を印ごとにする | 採らない。分ける物が無くなる |
| 直さない | リンクを渡す相手に口で伝える | 採らない |
| **予想の段を無くす** | 開いたらすぐ作る | **本人の決定** |
| 予想のギャラリー | 人の書いた予想を並べて見せる | 本人が止めた。作った物のギャラリーにする |

## 置き換わる物

- 予想か自分の仮説が無いと仮説の一覧も型紙も出さない門（F9.prediction、[J-002](J002-mechanism-hypotheses.md)）
- 予想の段を前提にした順路（[J-024](J024-entrance-and-workshop.md) の入口、サイトの要件定義の順路）
- タップで予想を選ぶ形（U-44、Issue #118）

凍結した基準の F9.prediction を変える事になるので、作りの変更の時に理由を commit と `docs/claude-usage.md` に書き、照合の表も同じ commit で直す。

## この決定の外にある物（書き手の整理）

- 凍結の床（必須 2 種の紙の指紋）は壊さない。紙の版を変える時は次の版として足す
- 人の説明が先に AI が返す順（[J-013](J013-core-words.md)）と、順位を付けない事（[J-025](J025-no-ranking.md)）は変わらない。ギャラリーも順位を付けない

## 読みで止めている事（本人に確かめていない）

本人の言葉は「予想の段」で、次の物には触れていない。答えが無ければ、この読みで進める。

- 自分の仮説を立てる道（[J-008](J008-own-hypothesis-path.md)）は残す
- くずし字の頁の「先に自分の読みを書く」は残す（予想でなく読みの練習）
- 必須 2 種の紙にある予想の欄は、今の版を変えない
