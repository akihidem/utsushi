# J-027 工作の様子を蓄積して、サービス全体の改善に回す

- **状態**: 本人の決定（2026-11-05 朝、窓口を通して届いた）
- **本人の言葉**: 「子供の工作の様子を蓄積して、サービス全体の改善をするようにする」
- **窓口の補足**: 型紙だけでなく、案内・聞く口の答え・サイトの流れの改善に回す。Physical AI のデータ取りの、子ども工作版という位置づけ。個人の情報は落とす決まりはそのまま
- 何をどう改善するかの具体案と段取りは [research/29](../research/29-making-data-to-service.md)

## 残す物と残さない物

| | 残す | 残さない |
|---|---|---|
| 聞く口の質問 | 玩具・仮説・版・質問の文（200 字まで）・どの答えで返したか・時刻（分まで） | IP・機器の名前・cookie・名前・答えの文・声 |
| 記録 | 動きの札・感想・止まった所・直した点・時間・どの版か | 名前（「書いた人」は説明の欄だけ。自由な名乗り） |
| 写真と動画 | 作った物（記録に添えた物。撮影の情報は落とす） | 顔・声。子どもの写真と声は扱わない線のまま |
| カメラ（かざして選ぶ） | 選んだ札だけ | 映像（端末の外へ出さない） |

連絡先の形（メール・電話・郵便番号）がある質問は、文を残さず、落とした事だけを数える。**名前は機械では落とせない。** 聞く口のすぐ下に「名前は書かないでください」と出し、作る側が読む時に消す。

## 出し方の線

- 学ぶ人の頁には、集計・割合・順位を出さない（J-025）。
- 作る側の頁（/loop と、玩具ごとの様子の頁）にだけ、聞かれた事の多い順・止まった所の言葉・感想・版ごとの動きの札の数を出す。頁の頭に「作る側の集計。順位ではない」と書く。
- 版ごとの動きの札の数を作る側の頁に出す事は、型紙の版を上げるかを決める材料として要る。学ぶ人の頁の節と一覧には出さない。

## 断りの文（案。本人が決める）

- 玩具の頁の聞く口: 「聞いた言葉は、名前や連絡先を除いて、案内と答えを良くするために残します。名前は書かないでください。」
- 手帖の聞く口: 「聞いた言葉は字にして、案内を良くするために残します。声と映像は残しません。名前は言わないでください。」

## 決まっていない点

- 残す期間。
- 学校や催しで使う時の、保護者と先生への断りの出し方。
- 「時間の目安」の札を学ぶ人に出すか（順位を付けない線との関係）。
- サイトの記録をエンジンの報告の形で渡す橋を、どちらが持つか（J-026 の受け持ちの続き）。
