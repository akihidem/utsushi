# J-003 Claude に絵を拡大する道具を渡す

- **状態**: 道具は作った。仮説生成に組み込むかは、比べてから決める（`research/04` の Q3）
- **きっかけ**: 側面の棒は、見開き全体では細い線で、部分の拡大で 2 本線だと分かった（`research/01`）。
- **比べた案**:

| 案 | 長所 | 短所 |
|---|---|---|
| 頁全体を 1 枚だけ渡す | 単純で安い | 細部を見落とす恐れ。側面の棒の経験から |
| 決まった位置で切った数枚を最初から渡す | 道具が要らない | 毎回同じ費用がかかり、どこを見たかが理由にならない |
| **Claude が領域を指定して拡大する道具** | 見た場所が根拠として記録に残り、人が確かめられる | 呼び出しの回数と費用が増える。1 生成 8 回の上限の中で使う |
| Web で作例も探させる | 情報が増える | 権利を確かめられない資料が混ざるので捨てた |

- **決めた事**: 頁の中だけを見られる道具にする。隣の頁は見られない。
- **未確認**: 実際に根拠が具体的になるかは、Claude の API でまだ比べていない（$500 枠を使う前に台帳へ書く）。
