# J-034 頁に出す字は AI が整理した字だけ。話した字は作る側だけが読む

- **状態**: 本人の決定（2026-11-06、窓口を通して届いた）。11-05 の決め「記録に入った工夫の字は、記録の感想と同じに、ほかの人の頁に文で出す」（`src/web/hanasu.py` の方針）を変えた
- **本人の言葉**: 「頁に出す字は B。AI が整理した字だけを出す（話した字は作る側だけが読む）。」
- **問い**: #335 の残る事「頁に出す字を、話した字のままにするか AI が整理した字にするか」。もとは本人の方針（11-05 19:45）「仮説も記録も音声や動画にしてAIが整理する形にするのはどう。文字で記入がオプションの扱い」

## 決めた事

- 話した字（仮説を見て話した考え・作りながら話した工夫・上げた後に足した字）は、記録に結んでいても、学ぶ人の頁に出さない。手帖の記録の札・ギャラリー・玩具の頁のどれにも出さない
- 頁に出すのは、AI が整理した字だけ。整理した字の置き場は、まだ無い。できるまでは、記録の札に話した字の行を出さない（置き場ができたら、その字を出す形で作り直す）
- 記録の欄に手で書いた直した点（部品・変えた事・結果）は、今までどおり記録の札の「工夫した所（直した所）」に出す。書く欄に書いた字として出してきた物で、この問いの外
- 話した字は消さない。記録に結んだまま、作る側の頁（/loop/<印> の「7 話した事」と /loop/ayumi の版の歩み）と、輪と束の材料（Claude が読む物）に入る
- 「残す」を押した後に、残した字を口の下に並べる所は残す。話した本人がその画面で確かめるための物で、頁を開き直すと消え、ほかの人の頁には出ない

## 比べた案

| 案 | 中身 | 判断 |
|---|---|---|
| A | 話した字のまま頁に出す（11-05 の形） | 本人が選ばなかった。名前は機械で落とせず、話した字は書いた字より名前や言い癖が混ざりやすい。読み直さずに残る事も多い |
| B | AI が整理した字だけを出す | 採る（本人の決定） |

置き場が無い間の作り方は、3 つを比べた。

| 作り方 | 判断 |
|---|---|
| 話した字の行を、今すぐ頁から外す | 採る。B と食い違う形を残さない |
| 整理した字ができるまで、話した字を出し続ける | 捨てる。B と食い違う間、話した字がそのまま人の目に触れる |
| 整理する所を今作る | 捨てる。新しい欄と Claude を呼ぶ道が要り、今は開いている直しと決めた字だけを入れる時期（11-06）。本物の API も回していない |

## 前の決定との関係

- **J-028（合言葉なしで開いた場）**: 前から、開いた場では節ごと出さない。変えない
- **J-013（AI の返事は人の説明と思いつきの後）**: 変えない。整理した字を出す時も、この順に合わせる
- **話した工夫を、ギャラリーにも出す枝（PR #392）**: この決定で要らなくなったので閉じた。整理した字の置き場ができたら作り直す
- **作る側が隠す道具（`talk_log.set_share`）**: 学ぶ人の頁から隠す道具だったが、今は輪と束の材料から外す道具になる

- 試験: `tests/test_talk_not_shown.py`（学ぶ人の 7 つの頁に 3 つの場面の字が出ない・直した点は出る・作る側には残る）。直す前の main で落ち、直した後に通る（`docs/process/gate-evidence/red-talk-not-shown.txt`・`green-talk-not-shown.txt`）

## 確かめていない事

- 整理した字を作る所と、その字を出す頁の文。文は本人の確認が要る
- 人が使った確認。記録の札から話した字が消えて、話した人が「残らなかった」と思わないかは、まだ見ていない（「残しました。型紙や説明をよくするのに使います。」の返事は出る）
