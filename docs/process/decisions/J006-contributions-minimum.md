# J-006 持ち寄りの場は、確認つきの受付を先に作る

- **状態**: 決定（範囲に入れるのは本人の決定。最小の形は Claude Code のセッションの判断）。外の人の入口と公開の条件は本人の判断待ち
- **比べた案**と捨てた理由は `research/09`。
- **決めた事**: 手元の画面で受け付け、人が確認してから公開する。他人の写真・文・連絡先は、本人の答えが出るまで repo に入れない。
- **理由**: 他人のデータを扱うので、入口より先に、確認・権利・取り下げの決まりを動かす必要がある。
- **検品**: 他人のデータを扱うので、別のセッションによる検品を通す。
- **検品の結果**: 別のセッションの検品を 2 回受けた。1 回目は重い指摘 8 件、2 回目は修正から生まれた重い指摘 4 件（端末の確認が開けない、電話番号の検査の後退、効かない取り下げ、写真の向き）で、どれも直して負の対照を足した。
