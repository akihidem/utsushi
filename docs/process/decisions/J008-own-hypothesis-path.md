# J-008 仮説を自分で立てるところから始める道を足す

- **状態**: 決定（本人の設計入力）。最小の形を作った
- **きっかけ**: 本人「最初の仮説のところから自分でやりたい人もいるかも」。予想だけでは、推理の一番面白い所を AI や作者の案に渡してしまう。

## 2 つの道

| | 予想から入る道 | 自分の仮説から入る道 |
|---|---|---|
| 1 | 図を見る | 図を見る |
| 2 | 予想を 1〜3 行書く | 自分の仮説を書く（動かし方・図のどこを見たか） |
| 3 | 仮説が並ぶ | 自分の仮説の型紙を刷る（型紙にできる形なら） |
| 4 | 1 つ選んで刷り、作って試す | 作って試す |
| 5 | 記録で順位が変わる | 自分から比べたい時に、用意された仮説を並べて見る |

## 比べた案

| 案 | 良い点 | 悪い点 | 判断 |
|---|---|---|---|
| 予想の欄を長くするだけ | 作る量が最小 | 自分の案を型紙にできず、結局用意された案を選ぶ | 捨てた |
| 用意された仮説を、試し終えるまで機械で隠す | 順番が守られる | 試す前に比べたい人を止める。行き詰まった人の出口が無い | 捨てた。順番は本人が選ぶ物にする |
| **自分の仮説を 1 件の記録にし、比べるのは本人の操作にする** | 順番を選べる。作者の案より先に自分の案が残る | 先に見てしまう人は止められない | 採る |

## 決めた事

- 予想か自分の仮説のどちらかを書くまで、用意された仮説は見せない。
- 自分の仮説には、動かし方と根拠（図のどこを見たか）を求める。寸法や押し方は任意。
- 今の雛形に乗らない仮説も記録として残す。「型紙にできない」と伝え、雛形にある機構を作れるふりをしない。
- 比べる時は、自分の仮説を先に、用意された仮説と同じ形で並べる。どちらが正しいかは言わない。
- 自分の仮説は個人の記録なので git に入れない。

## 範囲への影響

小さい。画面の入口に分かれ道が 1 つ増える。Claude が実行時に仮説を立てる段（未実装）は、「自分の仮説を見てから出すか」を入力に受ける形にする。今の用意された仮説は Claude Code のセッションが書いた案で、実行時の AI の仮説とは別物。
