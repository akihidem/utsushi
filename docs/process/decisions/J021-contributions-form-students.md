# J-021 持ち寄りの場の入口は既製のフォームにし、生徒の記録と本人のインタビューを載せる形にする

- **状態**: 入口は本人の決定（2026-11-03、窓口を通して届いた。カード 20261102-153559 の案 2）。生徒と本人のインタビューを載せるのは本人の意向。下の設計は作る側の案で、本人が変えられる
- **本人の言葉**: 「2 を採用（既製のフォームで受けて、確認して手元へ取り込む）」「持ち寄りの場には、本人の生徒と本人自身のインタビュー記録が載る形がよい。生徒が試した記録・声と、本人のインタビューを載せられる中身として設計すること。生徒は未成年なので、同意の取り方と個人が特定されない形の扱いを設計に含めること」
- **実装**: まだしていない。下の「まだ集めない」と「本人に聞く事」の答えで形が変わるため。実装する時は他人の、それも未成年のデータを扱うので、出荷の段で別のセッションの検品を通す（[J-006](J006-contributions-minimum.md) と同じ）

## 入口: 既製のフォーム → 手元へ取り込み

```
フォーム（外部の事業者）→ 本人が CSV で書き出す → 手元で取り込み（今の受付と同じ検査 F10）
   → フォームの回答を消す → 人の確認 → 公開の記録 → 公開の頁・Claude の道具
```

- 取り込みは今の `submit` を 1 行ずつ通す。検査を 2 つ作らない。通らない行は取り込まず、理由を本人に見せる
- 取り込んだ後、フォームの側の回答と、書き出した CSV を消す。外部の事業者に残る期間を短くするため
- フォームでは回答者のメールアドレスを集めない設定にする。連絡先は任意の欄にし、今どおり公開の記録に入れない
- 写真の添付は、フォームによっては回答者のログインが要り、ファイルがフォームの持ち主の保管場所に入る。写真は今週の入口に入れず、要る時はフォームの種類を決めてから足す
- **生徒はフォームに直接書かない。** 本人が生徒の記録を、名前を外した形で代わりに入れる（下の「生徒の記録」）。未成年のデータを外部の事業者に渡す量を最小にするため

## 載せる中身

今の 4 種（写真・情報・思い出・作り方の知見）に 2 種を足す。

| 種類 | 中身 | 書く人 | 要る欄 |
|---|---|---|---|
| trial 試した記録 | 型紙で作って試した結果。今の試行の記録と同じ「動いた／動かない／わからない」と測った角度（[J-009](J009-sheet-and-records.md)） | 生徒の分は本人が代わりに。大人は自分で | 玩具、型紙の版、結果、測った値（あれば） |
| interview 聞き取り | 本人への聞き取り。問いと答えの組 | 聞き手が問いを書き、本人が答える | 聞き手、聞いた日、本人が読んで確かめた印 |

生徒の「声」は試した記録に付ける短い文（予想・やってみて思った事）にする。種類を分けないのは、声だけが記録から離れて一人歩きしないため。

**立場（role）に `student` と `teacher` を足す。** 本人の聞き取りは `teacher`。確かさの種類は今の 6 つのまま使う（生徒の試した記録は「見た」、予想は「推測」）。

### 本人のインタビュー

- 聞き手は Claude にする案を推す。Claude が問いを作り、本人が書いて答え、本人が読んで確かめてから載せる。人の聞き手を立てない形は [J-018](J018-no-peer-review.md) とも合う
- 名前を出すかは本人が選ぶ。**ただし本人を名前で出すなら、勤め先・学年・地域は本人の聞き取りにも生徒の記録にも書かない。** 本人が特定されると、生徒の記録が「この先生の、この学校の子」まで辿れるため

## 生徒の記録の扱い

### 同意の取り方

| 段 | 中身 |
|---|---|
| 1 学校や教室の許可 | 勤め先の決まりがあれば、それに従う。作る側は中身を知らない |
| 2 保護者の同意 | 紙で。載せる中身・載せる場所・誰が見られるか・取り下げ方を書く。公開の範囲を 3 つから選ぶ（この場所での表示だけ／CC BY／載せない）。提出物に入れる選択肢は置かない |
| 3 生徒本人の同意 | 保護者とは別に、生徒に分かる言葉で聞く。保護者が良くても本人が嫌なら載せない |
| 4 断っても何も変わらない事 | 本人は生徒の先生なので、頼まれると断りにくい。断っても授業や評価に関係ない事を紙に書き、保護者を通して返事をもらう |
| 5 取り下げ | 生徒・保護者のどちらからでも、いつでも。本人に伝えれば、手元の取り下げ（`withdraw`）で公開から外す |

- 同意の紙は本人の手元に置き、repo にも外部の事業者にも入れない
- 記録の側には、同意の紙と結ぶ番号（例 `S-03`）と、2 と 3 の有無、公開の範囲だけを持たせる。番号と名前の対応表は本人の手元だけ
- 年齢で同意の要り方を分ける法の解釈は、作る側はしない。全員に保護者と本人の両方の同意を取る形にして、年齢の線を引かずに済ませる

### 個人が特定されない形

| 載せない | 代わりに |
|---|---|
| 名前、あだ名、イニシャル | `生徒 S-03` のような番号 |
| 学校名、学年と組、地域、試した正確な日 | 「小学生」のような大きなくくりと、月まで |
| 写真（手や持ち物が写る物も）、録音、手書きの字の画像 | 本人が文字にした文 |
| 家族・友だちの名前、病気や家の事 | 本人が確認で消す（書き換えでなく、その文を載せない） |

- **少ない人数は、くくっても特定されうる。** 3 人の教室で「小学生の女の子」と書けば分かる。性別は載せず、人数が少ない間は年齢のくくりも外す
- 生徒の記録の公開は、今の検査に加えて次を見る（作る時に F10 に足す）。生徒の記録に同意の番号と 2 つの同意がある事、表示の名前が番号の形だけな事、写真が付いていない事
- 機械の検査は名前や学校名を拾えない。最後は本人が全文を読む確認に頼る。これは今の F10.pii と同じ限りで、検査だけで安全とは言わない
- 生徒の記録は Claude の道具（`list_contributions`）へ渡す時も、公開の範囲が CC BY の物だけにする。今の「表示だけは外部の API に送らない」と同じ線

## まだ集めない

今週は生徒の記録を集めない（J-013 の 6 のまま）。理由は 3 つ。

1. 保護者の同意の紙が行って戻るのに日がかかり、11-08 の提出に間に合わせると急かす事になる
2. 提出物は公開で主催に永続の許諾を与えるので、子どもの記録を入れると取り下げが効かない
3. 本人の決まり「子どもの記録は今週集めない」を、本人がまだ外していない

だから今週見せられるのは、本人の聞き取り（大人）と本人の試した記録、それと生徒の記録を受けるための同意の紙と形まで。**生徒の記録が無いのに、あるように見せない。** 架空の生徒の記録は作らない。

## 本人に聞く事

1. 生徒の記録を集め始めるのはいつか。推し: 提出の後。今週は形と同意の紙だけ
2. 生徒の「声」は、書いた言葉か、話した言葉を本人が文字にした物だけでよいか（録音と写真は扱わない決まりのまま）
3. 生徒はどこの子か（勤め先の学校か、教室か）。学校なら勤め先の許可が要るかを本人が確かめる
4. 本人の聞き取りの聞き手を Claude にしてよいか。本人の名前を出すか
5. どのフォームを使うか（推し: Google フォーム。案件の置き場にすでに Google Drive を使っているため）
