## 3: 手元のブラウザの画面（作った）

`PYTHONPATH=src .venv/bin/python -m web.play_server` で `http://127.0.0.1:8766/` に開く。持ち寄りの画面と同じく、手元の名前にだけ応じる。

| 画面でできる事 | 守る線 |
|---|---|
| 玩具を選び、図と歌を見る | 歌は人が確かめた読みだけを、原文の引用の印で出す。採らなかった読みは出さない |
| 予想を書く／自分の仮説を書く | 予想か自分の仮説の前は、用意した仮説を見せず、型紙も刷らない（F9.prediction） |
| 仮説を見て、型紙と手順の紙を刷る | 並びは元の記録の順で、順位を出さない（J-013） |
| 試した記録を残す | 値は雛形の決まり（御来迎は 3 値、虎は 2 値）。動かなかった記録もそのまま残す |
| 試した後の紙を開く | その仮説の記録を残すまで出さない。URL を知っていても渡さない（J-013） |
| 何が起きたかの説明と次の思いつきを書く | 人の説明が先。画面から Claude は呼ばない |

試験は `tests/test_play_server.py`（予想の前、別のサイトからの送信、試した後の紙の出し方、決まりの外の値、説明の 2 欄）。**人がブラウザで使った確認はまだ。** 画面の見た目は目で確かめていない。

### 見た目: ルックブックの様式（本人の指定、11-03 夜）

本人の言葉: 「ルックブックみたいな、この前共有した X の記事みたいなやつ」。11-02 の「本形式の見た目」と同じ参照で、記事の実物は窓口でもまだ特定できていない。当面は様式だけを写した。

- 入口: 表紙の題と短い文の後、玩具ごとに見開き（大きな図と、名前・縦組みの歌・ひらく導線）。玩具ごとに図の左右を入れ替える
- 玩具の頁: 頭を見開きにし、操作の欄はその下。仮説は図版の 1 枚のように並べ、大きな字は名札で順位ではない
- 図は手元に取ってある NDL の頁（所蔵の表示つき）。歌の引用の印は短くしても消さない
- 狭い画面では 1 列に積み、歌は横組みに戻す
- 見た目の塊（`LOOK`）と 2 つの頁の組み方だけを替えれば、記事の実物が届いた時に寄せ直せる

画面の写しで目で確かめた（幅 1400 と 420）。人がブラウザで使った確認はまだ。
