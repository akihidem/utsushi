# J-014 名前を utsushi にする

- **状態**: 本人の決定（2026-11-02）。窓口を通して届いた
- **決めた事**: 名前は `utsushi`。GitHub の repo 名も同じにする

## 決め方の経緯

| 順 | 起きた事 | 誰が |
|---|---|---|
| 1 | 開発中の呼び名は「うつしかがみ」。`utsushikagami` 確定と届き（15:50）、すぐ再検討になった（15:51） | 本人、窓口を通して |
| 2 | `toy-kagami` 確定と届き（15:59）、受け皿の担当が空の非公開 repo を作った。その後 `utsushi` の案で再検討になり（16:00）、全体を参照して決める事になった（16:04） | 本人、窓口を通して |
| 3 | 候補を比べ（[research/11](../research/11-naming.md)）、「鏡は仕組みに実在しないので比喩として弱い」として `karakuri-yomi` を推した | Claude Code のセッション |
| 4 | 「かがみは仕組みの話でなく、AI は鏡、江戸の絵を映すことはできるが映すだけでは遊べない、という哲学の話」と訂正した | 本人 |
| 5 | 推しを取り下げ、推しなしで 6 候補を並べて本人に渡した | Claude Code のセッション |

選んだ理由は本人から聞いていないので、ここには書かない。

## 比べた時の見立て（research/11 から）

| 伝わる | 伝わらない、または衝突する |
|---|---|
| 写し・映し。古い物に倣って作る工芸の語に通じる。短い | 鏡の語が抜ける。仮説と試行は名前に出ない。忠実な写しに聞こえ、「復元ではない」と少し衝突する |

同じ名前を含む repo は GitHub に 48 件あった（部分一致を含む検索）。
