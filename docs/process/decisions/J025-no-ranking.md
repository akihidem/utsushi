# J-025 仮説の順位をやめ、記録は「次に試す物」の提案の材料だけにする

- **状態**: 本人の決定（2026-11-03 夜、窓口を通して届いた。カード 20261102-225932 の (b)）
- **本人の指示**: 凍結した基準の文と `loop.py` の順位の部分は、理由を記録して直す

## 理由

[philosophy.md](../philosophy.md) の点検で、記録で仮説の順位が動く作りは「動いた事を正しさとして扱う形」で、学ぶ人に見せなくても構造は成績のままだと分かった（O-18）。哲学は「動かない事は失敗でなく自然の返事」「記録は成績にしない」と置いている。だから順位そのものを持たない。

記録は捨てない。次の手の提案（`loop propose`）が「次に試す仮説と、それを見分けるために測る事」を出す材料に使う。決めるのは人で、採っても仮説の並びは変わらない。
