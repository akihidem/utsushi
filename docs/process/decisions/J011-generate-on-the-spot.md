# J-011 AI がその場で仮説と寸法を作る段を本線にする

- **状態**: 作った。本物の API では 1 回も呼んでいない。質はまだ分からない
- **きっかけ**: 本人「ここを AI でその場で作るのが山場では」。固定の仮説と輪の後半を先に作っていて、製品の中心が空いていた。

## 流れ

```
図（NDL）・歌・使い手の予想か自分の仮説・確定した記録
  → Claude が前例を引き、必要なら図を拡大し、仮説 2〜3 本と寸法の案を出す
  → 決定的な検査で落ちたら理由を読ませて直させる（2 回まで）
  → 人が採る → 決定的な描画器が紙を描く
```

## 比べた案

| 論点 | 採った案 | 捨てた案と理由 |
|---|---|---|
| Claude の出力 | 仕組みの読みと寸法の JSON | SVG を直接描かせる: 寸法・重なり・印の検査が守れない。本人の指定とも逆 |
| 雛形に乗らない読み | `template_id: null` で残す | 雛形へ無理に落とす: 推理が寸法の選択に縮む（Q2）。型紙は出ないが、読みとしては残す |
| 固定の仮説 | 物差しと、AI が使えない時の受け皿に残す | 消す: 比べる相手と、鍵が無い人の入口が無くなる |
| 見せる順 | 予想か自分の仮説の後 | 先に見せる: 答えに引きずられる |
| 図の渡し方 | NDL の図を base64 で渡す | 手元の複写を渡す: 権利が未確認。Web で探させる: 権利を確かめられない |

## 予算の中での設計

`src/api/budget.py` が、呼ぶ前に毎回、日割りの上限・累計の停止線 $475・1 回 $3 の上限を見積もりで確かめて止める。正は Console。

1 回の見込みは 5〜15 万入力・3 千〜1 万出力トークン【推測】で、Opus 5.5 なら約 $0.3〜0.8。呼ぶ前に台帳へ用途と見込みを書く。

## 確かめる事

- 図と歌だけから、絵の側面の棒や首の穴に自分で気づくか。
- 既知の作例を学習で知っている可能性があるので、「絵だけから当てた」とは言わない。
- 固定の仮説との差を、同じ予想で比べる。
