## 哲学とぶつかる所

[哲学](../philosophy.md)は「動かない事は失敗でなく、自然の返事」「記録は成績にしない」と置いた。[J-013](J013-core-words.md) は「正誤・原因・解釈・次の手を子どもにリアルタイムで返さない」「人の説明が先」と決めている。「AI が判定する」をそのまま作ると、紙の返事の上に AI の採点が乗る。（11-04 に本人は、子どもも AI から直接返事をもらってよいと決めた。AI が返事をする事自体はぶつからない。ぶつかるのは採点の方である）

そこで「判定」を、哲学の 3 つの物差しで分ける。

| 何を判定するか | 誰の物 | Claude がしてよいか | 例 |
|---|---|---|---|
| 型紙は組めたか、寸法どおりに動く作りか | 作り手 | **してよい。** 道具の品質で、学ぶ人の評価ではない | 「扇の 3 枚目の折り目が戻っていて、そこで止まって見える」は型紙の直しの材料 |
| この紙に何が起きたか | 学ぶ人 | **観察として書くだけ。** 成功・失敗・点数は付けない | 「筒を下げ始めてから約 1 秒で扇が開き始め、半分ほどで止まった」 |
| 予想が当たったか | 学ぶ人 | **しない。** 予想と紙の返事を比べるのは本人。Claude は本人の記録と動画の食い違いだけを示す | 「記録の角度は 172°、動画の最後のコマからの見積もりは 150° 前後。測り直すかは本人が決める」 |

この線なら紙の返事が先に来て、採点にならない。Claude の役は、紙の返事を見落とさないための**観察の補助と記録の整理**で、その観察は学ぶ人に直接返してよい（11-04 の決定）。本人の言葉の「判定」は、1 行目（型紙の判定）と、記録との食い違いの指摘として受ける。

### 出し方の決まり（案）

- **本人の説明の後に出す。** 今の輪の順（記録 → 本人の説明 → Claude）に `observe` を入れる。本人が何が起きたかを先に書き、Claude の観察はその後に並べる（J-013 の 5）
- **学ぶ人に直接返してよい。** 子どもを含む（2026-11-04 の本人の決定で、前の「大人にだけ返す」を取り下げた。J-013 の決める点 2 の変更）。今週の記録は本人のものだけで、子どもの記録・写真・声は扱わない線は変わらない
- **印を付ける。** Claude の観察は図鑑の文の印（[J-016](J016-zukan-labels.md)）の「観察」とし、見たのが Claude で、元が動画のコマである事を書く。人の観察と混ぜない
- **言葉を絞る。** 「成功」「失敗」「正解」「良い」「惜しい」を使わない。数は見積もりと書き、確かさを付ける。原因は断定せず「〜に見える」までにする。次の手は書かない（次の手は本人の思いつきの後、今の `propose` の段で）

### 動画の扱い

- Claude の API は動画をそのまま受けないので、手元の `ffmpeg` でコマを抜き、音は捨てて画像として送る。コマの数に上限を置く（案: 1 本 16 枚まで）
- **人の顔と声を入れない。** 子どもの写真・声は扱わない決まりのまま。今週の動画は本人の手だけ
- 動画とコマは repo に入れない。記録と同じく git の外に置く
- 角度は人が分度器で測った値を正にする。コマからの見積もりは、写す角度とレンズで大きくずれるので、照らし合わせの補助にとどめる
- 鍵（O-03）が届くまで本物では呼べない。それまでは鍵の要らない試験（コマ抜きと、出力の言葉の検査）だけ作れる

## 再現ギャラリー

試した記録 1 件を 1 枚にして並べる。並べるのは記録の順で、**順位や「よく動いた順」にしない**（J-013 の 4）。

| 1 枚に載せる物 | 出所 |
|---|---|
| 玩具と仮説と型紙の版 | 記録 |
| 本人の予想 | 試行の紙（[J-019](J019-experiment-sheet.md)） |
| 紙の返事（動いた／動かない／わからない）と測った値 | 記録 |
| 動画のコマ数枚 | 本人の動画（本人の許可がある物だけ） |
| 本人の説明と思いつき | `explain` の段 |
| Claude の観察（印付き） | `observe` の段 |
| 有識者の声（あれば） | 持ち寄りの場 |

- **「再現」の言葉に注意。** 哲学は「昔の玩具が再現されたかは測り切れない」と置いた。ギャラリーの見出しに「試した記録」を添え、「再現できた」とは書かない
- 開かなかった記録も同じ大きさで並べる
- 作りは手元で記録から静的な頁を書き出す形にする。公開のサーバは作らない（[research/09](../research/09-contributions-design.md) の D と同じ理由）

## 有識者の声

- 持ち寄りの場の投稿に「どのギャラリーの 1 件への声か」の欄を足す。種類は今の「作り方の知見」と「情報」を使い、確かさの種類も今のまま付ける
- 公開は管理者の本人が決める（J-021 の公開の条件）
- 有識者の声も成績にしない。「この作りは昔の職人ならこうした」のような知見として載せ、記録の評価としては載せない
- **今週、実際の有識者の声は 0 件の見込み。** 架空の声は作らない。見せられるのは、声を受けて 1 件に結ぶ仕組みまで

## この案で分からない事

- **Claude がコマから紙の動きをどこまで読めるかは、1 回も試していない。** 折り目の戻りのような細かい所は読めないかもしれない。最初の数本で、本人の記録と比べて確かめる
- 観察の言葉の決まりを守れるかは、出力を検査しないと分からない。決めた語を使わない事は機械で見られるが、評価めいた言い回しは機械で拾い切れない
- 有識者に当てがあるかは、作る側には分からない

## ③で上げた写真と動画の出し方（2026-11-05、本人の決定）

- 決まった事（#275 の決める点 1）: 物だけが写った写真と動画は、ギャラリーで公開する。人や声が入る物は、字だけにする（映像と声は頁に出さない）。出す前に、人の確認を入れる
- 作り（#314）: 確かめるのは人だけで、機械は顔も声も見分けない。`omochae.media_review` の命令は、持ち寄りの公開と同じく端末で人が番号を打った時だけ進む。確認の前の物と、人や声が入るとされた物は、ギャラリーと玩具の頁の「他の人が作った物」に出ない
- 確認の前の物（11-06 の直し）: 上げた本人の画面にだけ出す。別の人の手帖と絵の道には出さない。上げた時に渡す鍵で見分け、次の記録と期限で閉じる（`omochae.media_review` の `shown_to`）。確認の前の動画を Claude に渡す口と読んだ文も、同じ画面だけにする（別の人は 403）。
- 動画の音は取り込みで落とす（本人の決定の文「声は字にして、声そのものは残しません」）。前は音を残して、頁で消音にしていた
- 手帖の札は、確認の前の物を上げた本人の画面にだけ出す。上げた人が受け取りを確かめる所で、上げた時に渡す鍵で見分ける（11-06 の直し）。別の人の手帖には札の字だけが出る。人や声が入るとされた物は手帖にも出さない
- この決定で変えない線: 合言葉なしで開いた場では写真と動画を受けず、出さない（J-028）。（追記 11-06: 本人の決定で、開いた場でも受け、物だけと確かめた物はギャラリーにも出す形に変えた。合言葉付きの場と同じ線。J-028 の追記）
