## 共通にしている知見

版を重ねて分かった事のうち、1 つの型紙だけでなく、ほかの型にも入れている物。「見分け方」は、どの型に入っているかを雛形のコードから数える印で、改善ループの頁（`src/web/ayumi.py`）が使う。「これから」は決まっただけで、サイトの紙にまだ入っていない。
