## 共通にしている知見

版を重ねて分かった事のうち、1 つの型紙だけでなく、ほかの型にも入れている物。「見分け方」は、どの型に入っているかを雛形のコードから数える印で、改善ループの頁（`src/web/ayumi.py`）が使う。「これから」は決まっただけで、まだ紙に入っていない。

| 知見 | どこから | ループ | 見分け方 |
|---|---|---|---|
| 見える面の折り線を刷らず、絵の色の境で折る | 試行の場の見学者の言葉から、本人の決定 d（11-04、goraigo-v9） | 2 | hide_folds |
| 凡例に、谷折りと山折りの向きを言葉で添える | つぶやき「谷折り、山折りがわからない」（11-04、goraigo-v8） | 2 | legend |
| はさみで切れる形にする（くり抜かない） | 本人の所見「くり抜く側面の穴を切るのが大変で、下から切り取ることになった」（11-04、goraigo-v8） | 2 | no_cuts |
| 図を貼らず、色と線を描き直す | 拡大した図の粗さと裏写り（goraigo-v4 から v5、J-007） | 前 | redraw |
| 最初に物差しを確かめてから切る | 家庭のプリンタでは、刷りの倍率が変わる事がある | 前 | ruler_first |
| 折る向きは「絵が外になるように」と言う（谷と山の言葉を使わない） | 組み立ての確かめと 11-04 の写真（J-033）。本物の紙で 1 枚折ってから次の版で替える | なし | これから |

「ループ」の欄は作る側の読み。前 = ループの前（試す前に、作る側が図と計算から直した版）、なし = どのループからでもない直し。

「変えた事」と「問題」は上の記録と commit から書いた。v1 と v2 の問題は次の版を作った理由から読んだ物で、実物の失敗ではない。
