# 11-04 の試行の写真と動画の、公開前の確かめ表（U-24）

- **目的**: 提出で repo を公開する前に、写真 9 枚と動画 1 本を公開してよいかを決められる形にする
- **なぜか**: 本人が試行の記録を全部（写真も）載せると決めた（U-09）。公開すれば被験者の写真も公開になるので、本人が「公開の前に 5 人の同意と顔の写りを確かめる」を提出前の確かめに足した（U-24）
- **どうしたらいいか**: 作る側が 1 枚ずつ写りを見て下の表にした（11-04 昼、元の大きさで見た）。推しは、5 人の同意がそろえば全部を載せたまま公開し、同意がそろわない人の手元が写る物、または下の「気になる所」を本人が外すと決めた物だけを、公開の前に外す（ファイルを消す commit を足す）。代わりに、写真を外して試行の文の記録だけを残す案もある
- **ゴールの要件**: 本人が 5 人の同意を確かめた（作る側は確かめられない）。下の表の「本人の判断」の欄が全部埋まっている。外す物があれば、公開の前にそのファイルが repo から無い（`git ls-files docs/process/trials/photos/20261104` で確かめる）

位置情報などの撮影情報は、載せる時に外してある（写真は EXIF、動画は撮影情報と音）。
