### 4 つの着目で読む（作る側の読み。本人の判定ではない）

| 着目 | 記録から言える事 | まだ言えない事 |
|---|---|---|
| おもちゃとして動いたか | 御来迎は、扇が開き像が立った形まで組めた物がある（p01・p07・p09）。ジャバラの固定に苦労した（本人） | 写真は止まった形で、押して扇が開いたか（動きとして）は写っていない。仮説 A と C のどちらが動いたか。虎は途中 |
| どうしたらもっと楽しいか | 「形ができるとあがる」「筒ができただけで目の色が変わって」（本人）。楽しさは形ができた所から始まった。始まる前は「つまんない」「切るのがめんどくさい」 | 最初の一歩を早くすれば楽しさが早く来るか（次の版で試せる問い） |
| 仕組みは納得できるか | 届いた言葉に、仕組みについての言葉は無い。「ジャバラに折る発想が出てこない」は形の作り方の詰まりで、仕組みの納得とは別 | 被験者が仕組みに納得したか。手順の紙・試した後の紙に書かれた事が届けば分かる |
| 哲学に沿った効果があったか | 「一人で作業できるところ」「話し合いよりはマシ」。手で試す時間に入った後は雑談が減った（本人）。哲学の「作っているうちに新しいアイディアが湧く」に当たる言葉はまだ無い | 予想を書いたか、作るうちに思いついた事があったか（手順の紙の「思いついた事」の欄） |
