## 優先の順（本人の追加指示、2026-11-04）

本人: 参照の X の投稿のルックブックについて「このルックブックの再現はしておきたい。このレベルなら実装はこれにしたい」。A と C の磨きは、そのルックブックの**再現度を基準**にする。この Skill 集の拾い方も**再現が優先**で、世界観を引っ張る物は入れない。

## A の作り替え（2026-11-04）

A 大判写真集を、上の観察の再現に作り替えた（`src/web/looks.py` の `taiban`）。写したのは組み方だけで、参照の写真と文は使っていない。

| 参照 | A での写し方 |
|---|---|
| 白いリングバインダーを真上から | 白い紙の見開きを白い板の縁で囲み、真ん中に金属の綴じ軸と 6 つの輪を CSS で描いた。見開きを縦に並べる（写真 1 枚目と同じ見せ方） |
| (1) 全面の写真と、灰色の箱の品物 | 1 枚目: 左に御来迎の図を全面、右に小さな文と玩具の一覧（入口なので）、灰色の箱に扇の切り抜き |
| (2) 平置きと番号の一覧 | 玩具ごと: 左に小さな図と縦の一行「どこが動くと思いますか」と 2 段の文（歌の引用と出典）。右は図の中の部分（扇、像、筒など）を切り抜きのように散らし、番号の一覧を添えた |
| (3) 見開きをまたぐ 1 枚 | 玩具ごと: 1 枚の図を左右の頁に半分ずつ敷く |
| (4) 文の頁と色見本の列、全面の写真 | 玩具ごと: 左に文と部分の寄りを 4 つ並べた列、右に図を全面 |
| (5) 余白の多い最後の見開き | 奥付: 左に扇の切り抜きと縦の一行「おもちゃで遊び続ける」（本人の言葉）、右下に出典 |

- **部分の名は、図に見える物の名**で、仕組みの名ではない（仮説を出さないため）。画面にもそう書いた。場所は作る側が図を見て決めた（`PARTS`）。「隣の像」は虎の図の隣に描かれた物で、何の玩具かは書いていない
- 図の写しの黒い縁（複写の台）が見えないよう、全面の図は少し大きく敷いた
- 参照の人物写真の役は、この作品では図の全面が担う。人の写真は使わない
- **めくる動き（動画の部分）は A に入れていない。** 本人が冊子型（めくる版）を残さないと決めたため。C をどうするかは本人に聞く（一覧の U-23）
- 確かめた範囲: パソコンの幅（1440）とスマホの幅（420）のヘッドレスの写し。人の目と本物のスマホはまだ

## 全体の見立て

中身の大半は、製品の UI（ドロップダウン、トースト、引き出し、ボタン）の**動き**の判断である。utsushi の入口は止まった紙の写真集とジンで、今は動きを 1 つも持っていない。だから一番効くのは、動きを足す話でなく、**足さない側の判断**（remove-animations の「抑制」）と、**スマホで紙面が崩れない細部**（mobile-native）だった。

## 拾う・拾わない

| 考え（出所の Skill） | utsushi での判断 | 理由 |
|---|---|---|
| 画面いっぱいの高さは `100vh` でなく `svh`（mobile-native） | **入れた** | A の表紙・見開き、C の表紙・留めた図が `100vh`。スマホでは URL の帯の分だけはみ出し、A の表紙の下の一覧と文が隠れる。写真集の 1 頁が画面にぴたりと収まる事は、紙面の佇まいそのもの |
| 数字の幅をそろえる（ui-cheatsheet の tabular-nums） | **入れた（今は C だけ）** | C の大きな番号（01、02）は主役の字。数字ごとに幅が揺れないようにした。A は作り替えで大きな番号が無くなった |
| 何度も見る所は動かさない。全部の節にスクロールで現れる演出を付けない（remove-animations、emil-design-eng の頻度の表） | **入れた（足さない事として）** | 入口は授業のたびに開く。紙が主役で、画面の演出は「映す」側にある（[philosophy.md](../philosophy.md) の 11-04 の言葉）。試験で、スクロールで現れる仕掛けが無い事を固定した |
| 動きの調子は作品の気分に合わせる（Sonner の「まとまり」） | **考えとして持つ** | もし動きを足すなら、速い UI の動きでなく、紙をめくる程度の静かな物にする。今は足さない |
| スクロールで写真を clip-path で現す（emil-design-eng） | 拾わない | 写真集らしく見えるが、上の「全部の節に演出を付けない」とぶつかる。速く読む人から中身を隠す |
| ボタンを押すと 0.97 倍に縮む、ドロップダウンの速さと曲線、ばね、ドラッグ | 拾わない | 入口に押す部品がほぼ無い（玩具の頁への字のリンクだけ）。玩具の頁の操作の欄は今回の範囲（A と C）の外 |
| 指で触れた時の灰色の点滅を消す、触れた後に hover が残る（mobile-native） | 今は拾わない | A と C に hover の演出が無い。点滅を消すなら代わりの手応えが要り、今は足す物を増やさない |
| 最悪のデータで壊す（break-ui: 長い名前、空の一覧） | **候補として残す** | 玩具は 2 つで名前も短い。持ち寄りで玩具が増えた時に、長い名前で大きな題（C は最大 72px、A は最大 110px）が崩れないかを確かめる価値はある |
| 次の日に見直す（emil-design-eng） | **やり方として拾う** | 本人の目で凍結の前に A と C を見る（U-22 の閉じる条件）と同じ向き |

## 入れた物（2026-11-04）

|---|---|---|

## この評価で分からない事
