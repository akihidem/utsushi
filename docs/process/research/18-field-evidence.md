# 18 現場の印象を補う記事と調査

本人の指示（2026-11-03 夜、カード 20261103-195236 の 2 と 3）: 具体の 1 場面を本人の逸話で置かず、「この印象を補完する記事や調査を探して」根拠にする。頻度の裏付けも調査で補う。架空の場面は書かない。

本人の現場は「学校の理科の授業や探究の授業」、印象を持った場面は「生徒の進路指導などで」（[research/17](17-field-and-continuers.md)）。印象は本人の言葉の「大型の科学実験装置やたくさんの計算資源を使う科学にしか真理がないと思ってしまう」（[philosophy.md](../philosophy.md)）。

**調べ方**: 作る側のセッションが、調べる役のサブエージェントに Web 検索を頼み、返ってきた報告から主な数を 1 つ一次資料で照らした（TIMSS 2023 の職業の問い。下の 1）。ほかの数は、報告が一次資料で読んだと書いた物と、二次資料だけの物を分けて載せる。

## 結論

- **この印象そのもの（真理は大きな装置の向こうにある）を測った調査は見つからなかった。** 本人の印象のままで、調査で裏付けたとは言わない
- **近い物は 2 つある。** (a) 日本の生徒は理科を楽しむが、中学で楽しさと自信が下がり、理科を使う職業に就きたい割合は国際平均の半分ほど。進路指導の場面の印象と向きが合う。(b) 海外の研究で、子どもは「理科をする」事は楽しんでも「科学者になる」事は自分と別の物と考え、科学者を実験室と装置の人として描く
- **印象と逆の事実もある。** 日本の生徒は手を動かす実験の回数が国際的にとても多く、約 8 割が「何が真実かを確かめる良い方法は、実験することだ」に賛成する。だから「手で確かめた事が無い」「実験で真実が分かると思っていない」とは言えない（[research/15](15-philosophy-review.md) と同じ）

言える形は「実験は多くしているのに、科学を自分の進む先と思う生徒は少ない」で、本人の印象の一部（距離）を支える。「大きな装置にしか真理がない」の部分は、本人の授業で短い問いを取るまで測れない。

## 要約とデモの冒頭に使う言い方（2026-11-04 に本人が「この文で採る」と答えた。U-16）

> 日本の生徒は実験を国際的にとても多くしている。それでも中学 2 年で「理科を使う職業につきたい」は 27%で、国際平均 58%の半分に満たない（TIMSS 2023）。本人は理科と探究の授業、進路指導の場で、生徒が科学を自分の手の届く物と思っていないと感じてきた。

最後の文は本人の印象で、調査の数とは分けて書く。「大きな装置にしか真理がないと思っている」とは、調査の言葉としては書かない。

## 本人の現場で確かめるなら

本人の授業で、短い問い（例:「科学の発見はどこで起きると思うか」）か、科学者を描く課題を取れば、印象そのものを測れる。生徒の記録になるので、[J-021](../decisions/J021-contributions-form-students.md) の同意の形が要り、今週はしない。
