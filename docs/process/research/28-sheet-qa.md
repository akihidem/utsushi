本人の方針（2026-11-05 朝）「型紙の洗練（組み上がりの完成度と動きの完成度）」のうち、画面と紙に出る紙の出来を、全部の玩具で検めた記録。
途中で方針が変わった（同じ朝の本人の決定）: 報告から型紙を直す輪は、入口も道具も型紙エンジンの側が受け持つ。雛形の code はエンジンの物なので、この検品では雛形を直さず、見つけた事をエンジンの報告の言葉（雛形・形・困り事の種類・手順の番号・一言）に寄せて書くだけにした。

## 直した物

無い。刷れない仮説（rc が 0 でない物）が 0 本だったので、仮説の記録の寸法を戻す直しも要らなかった。雛形の code には触っていない。

## 直さなかった物と案

- 1・2（番号の字の置き場）: 番号を穴の印と糊代の斜線から外す（穴の横へずらす、部品の外に引き出す）。雛形の側の直し。
- 3（番号の飛び）: 支えの形では支えを 3 にするか、手順の紙に「3 は台（この形では使わない）」と書く。雛形の側の直し。
- 4（部品の名前）: 型紙の札に名前を足す。小さな部品は番号だけにして、凡例の横に「番号と名前」の一覧を置く手もある。雛形の側の直し（形を変える判断が要る）。
- 5（最後の番号）: 遊ぶ動作は遊び方の欄だけに書き、組み方からは外す。雛形の側の直し。
- 6（虎の図の説明）: 雛形に図の説明の文を持たせる（試作の 7 雛形は持っている）。必須の 2 種の刷り上がりが変わるので、本人か型紙エンジンの側の判断。
- 7（試した後の紙の文）: 仮説の名前を「」で囲む（「棒の先に鳥を貼って振る」と「軸に掛け、振ると鳥が揺れる」を比べる）。仮説の記録の文なので utsushi の側で直せるが、今回の決まり（刷れない物を戻す直しだけ）の外なので案に留めた。

## 確かめていない事

- 手順の紙の残り 60 本（stand_figure の後ろの 5 枚ぶん・string_pull の後ろ・stick_prop の後ろ 2 枚ぶん）は縮めた紙を見ていない。機械の検査（番号・余白・凡例）は 171 本とも通した。
- 試した後の紙は字を雛形ごとに 1 枚読んだだけで、紙の割り付けは見ていない（余白の検査は通した）。
- 版 2 以降（報告から直した版）の刷り上がり。
