引用の外は書き手の整理で、本人の言葉ではない。表の状態は 11-05 午後の main のコードを読んで書いた。「ある」は main で試験が通っている物で、人が使った確認は別に要る。枝にしか無い物は「作りかけ」に書く。

## 一周の形

```
① 仮説を見ながら、自分の考えを話す → 反応して型紙が生まれる（ループ 1）
② 作りながら、工夫を話す → 型紙が直る（ループ 2）→ エンジンごと直る（ループ 3）
③ できた物を上げ、工夫と考えをカメラか音声で残す → ギャラリーで見られ、型紙もシステムも直る（ループ 4）
```

順番は本人の言葉のとおり。手で作る楽しさに気づく事が最初で、作った物が持ち寄られ、AI が良くなるのは後（副次的）。「作れて・壊せて・直せる」はその下に置く。

前提は本人の言葉のまま: 「型紙が正解ではなくて、とりあえずAIが考えた仮説であるということを明示する。システム側もそれを認識した上でループを回す」。

話した物が流れ込む先の形（サイトの線が用意し、声の担当と合わせる）:

- 字になった考えと工夫は記録の欄に入れる。②の工夫は手順の番号を付けて、工作の様子にも残す。
- 字の床は今の記録と同じ（長さ・連絡先）。声そのものは残さない。

## 守る線との当たり（本人の決定、11-05）

1. **③の写真と動画。** 物だけが写った物はギャラリーで公開する。人や声が入る物は字だけにする。出す前に人の確認を入れる（作りは #314）。
2. **声から字にした考えと工夫。** 名前と連絡先を除いた字で、作った本人の「出してよい」の合図がある物だけをギャラリーに出す。既定は出さない。取り下げられる（作りは #279 と #315）。
3. **③の説明文。** 本人が採った文を一字も変えずに使う（作りは #279。文は #318 と同じ窓口の案）。
4. **合言葉なしで開いた場。** ギャラリーは人の書いた文と写真を出さない（J-028）。ほかの頁（玩具の頁・手帖・図鑑）には、人の書いた説明や自分の仮説の文が出る所が残っている（別の目の点検で確かめた）。
5. **子どもが使う時。** 上の 1〜3 は成人の前提で書いた。子どもの場は同意の形を決めてから（research/31 の 4）。本人の答え待ち。

## 順番（本人の決定、11-05）

厚くする順は本人が決めた。

1. 作りながら話した工夫を、その場で記録に入れる（#279）。
2. サイトの記録を、エンジンの報告の形に渡す口（#278）。
3. 報告の集計から、エンジンの直しの Issue の案を起こす。直すかは人が決める（paper-to-toy #63 の続き）。

土台の #266（開いたらすぐ作る・ギャラリー・工夫の欄）は main に入った。

同じ決定で足した事: 職人や玩具店、実際に遊んだ人の情報も、同じ入口（ギャラリー・持ち寄り）で集める（#285）。

作り全体をこの 4 つのループの形にそろえる作業は U-60（#335）。

## 確かめていない事

- 人がこの一周を通した事。声の認識が工作の場の音で使えるか。
- 工夫の字で本当に型紙やエンジンが良くなるか。学習の効果と同じく、主張しない。
