# 27 全部の玩具に「たとえと、関連する事柄」を書く

本人の感想と指示（2026-11-05 朝、デモを見て、窓口を通して届いた）: 「扇を開くがとてもよくて、他のおもちゃでもこのようなアナロジーや、関連する事柄を書いて欲しい。できれば他のおもちゃでも同じようにやってみて欲しい」。

## 置き場と出し方

- 欄: `data/hypotheses/<印>.json` の `analogy`（`like` 身近な物へのたとえ、`related` 関連する事柄の一覧、`written_by`）。
- 頁: 玩具の頁の仮説の後、型紙の窓の前（`src/web/toy.py` の `analogy_section`）。印「作る側のたとえ」と「人の確認はまだ」「たとえは仕組みを考える手がかりで、答えではありません」を添える。
- 予想の前には出さない（F9.prediction。たとえは仕組みの手がかりなので、答えを先に見せない線と同じ）。
- 試験: `tests/test_analogy.py`（全玩具にある・長さ・成績の言葉が無い・予想の前後・順路）。

## どう書いたか

- 83 種のうち、必須の 2 種（御来迎・張子の首振り虎）は作る側（sub-site）が手本として書き、残り 81 種を 3 本の分身（枝 lane/analogy-a・b・c、27 種ずつ、別々の作業ツリー）が書いた。
- 各玩具の仮説の記録（動き方・根拠・試した後の紙の文）に合わせる。試した後の紙が「重心が支える面の上にある間は戻る」なら、たとえも重心と支える面の話にする。
- 身近な物: 折りたたみ傘・やじろべえ・シーソー・ハンマー投げ・ミニカー・ペットボトル・写真立て・積み木・だるま、など。仮説が違う仕組みを言う時は「〜の仮説は…の仲間です」と 2 つまで。
- 関連する事柄は「見出し: 説明」の形で 2〜5 本（重心・摩擦・てこ・ばね・振り子・転がり・音の出方・浮く力、仲間の玩具）。

## 守った線

- 成功・失敗・正解・不正解・順位・点数の語を入れない（J-025、哲学）。
- 昔の作り方や由来を言い切らない。名前は棚卸しの見立てなので「犬張子と見れば」「土の人形と見れば」の形で、玩具が何かを断定しない。正体のわからない物（コマ 4 の縞模様の小判形の物）は「置き方の仕組みの話」と先に断った。
- 仮説の名前の丸写しにしない（分身 b が山猫とのぼり猿で見つけて言い直した）。

## 確かめていない事

- 文の人の確認（`written_by` のとおり）。本人が読んで、たとえの当たり外れと言い回しを直す。
- 小学 4 年が読んで分かるか（言葉は寄せたが、人で試していない）。
- 物理の説明の厳密さは紙で試す範囲に留めた（遠心力の語は使わず「回る物は外へ飛び出そうとする」）。
