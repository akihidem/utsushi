# 11 名前を、できた物に照らして考え直す

本人の問い:「かがみ（鏡）の要素は仕組みの中に実在しないのではないか」。作品の全体（概念・過程の記録・実装・持ち寄りの場）に照らして調べた。

**事前メモとの関係**: うつしかがみの名と「AI は鏡。江戸の絵を映すことはできるが、映すだけでは遊べない」という考えは事前の下書きにある。下の照合はここで行った。

## 「鏡」は仕組みにあるか

`git grep` で、repo の中で「かがみ」は作品名としてしか出てこない。

| 鏡の意味 | 今の作品との照合 | 判定 |
|---|---|---|
| 1 つの像をそのまま映す | 仮説を複数並べ、1 つに決めない（J-002）。図も貼らず描き直す（J-007）。動きが逆 | 無い |
| 物理の鏡 | 部品にも画面にも無い | 無い |
| AI が絵を映す（事前の下書きの比喩） | 製品の中で Claude を呼ぶ所はまだ無い。作る仮説生成も「映す」より「推理」に近い | 比喩として弱い |
| 手本に照らして省みる（鑑） | 試した記録に照らして次の版と仮説を変える輪には近い。ただし輪はまだ実装途中で、この読みは説明なしには伝わらない | 将来なら一部ある |

**結論**: 本人の問いの通り、「鏡」は今の仕組みに実在しない。比喩としても、複数の仮説を並べる今の形とは合わなくなった。作品名を残すかは本人の判断。

## 作品の中心（名前が言い当てるべき物）

絵と歌だけが残る玩具の仕組みを、予想し、仮説を並べ、紙で試し、記録と人の知見で読み解いていく事。出口は紙で、画像解析や教育のチャットには見せない。

## 候補

GitHub の同名の repo の数は、名前での検索の結果（`utsushi` は部分一致を含む）。「写し」が工芸で名品を手本に作る事を指すという説明は一般的な知識で、調べた検索では定義を確かめられず、「仁清写」のような表記の例だけを確かめた。

| 候補 | 何が伝わる | 何が伝わらない | テーマ名との関係 | 同名 |
|---|---|---|---|---|
| `utsushikagami` | 作品名そのまま。音がきれい | 何をする物か。鏡は仕組みに無い | 同じ | 0 |
| `toy-kagami` | 玩具の物である事 | 鏡が無い問題は残る。試す事、江戸も伝わらない | 半分だけ残す | 自分の空の repo のみ |
| `utsushi` | 写し・移し。古い物に倣って作る工芸の語に通じる。短い | 仮説と試行。忠実な写しに聞こえ、「復元ではない」という主張と少し衝突する | 前半を残し、問題の「鏡」を外す | 48 |
| `karakuri-yomi` | からくりを読み解く事。「読み」は予想の意味も持ち、予想を先に書く設計に合う。人の知見を寄せる事も含められる | 紙で作る事 | 無関係。作品名を残すなら副題の関係になる | 0 |
| `tameshigami` | 試し紙。1 枚の紙で試す出口。画像解析に見えない | 江戸の玩具、持ち寄り | 無関係 | 0 |
| `omochae` | おもちゃ絵。今のコードの名前 | 試す事。絵の展示や画集にも読める | 無関係 | 0 |

## 見立て

`karakuri-yomi` が作品の全体に一番合う。日本玩具博物館の記事は御来迎を「からくり玩具」と呼んでいる。ただし「からくり」が虎の首振りにも自然に当てはまるかは未確認で、見立ては Claude Code のセッションの物。決めるのは本人。
