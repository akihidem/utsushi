# 32 話す・作る・残す の一周と、エンジンごと改善する輪（提出の核）

本人の言葉（2026-11-05 昼、窓口を通して届いた）:

> 今やってること。①インカメラか音声で AI が作った仮説を見ながら自分の考えを話す。②実際に作る。作りながら工夫などを話す。これをフィードバックとして型紙を改善するほか、型紙を生成するエンジンごと改善することができると面白いサービスになると思う。いまの実装でどこまでできる？

> ③できたものをアップロードして、工夫した点や考えなどをインカメラか音声で残す。ということをしてその内容をギャラリーで見れるし、システムも改善ループに入れる。としたい。

> 今話してるこの部分が今回のハッカソンの核になる！！

引用の外は書き手の整理で、本人の言葉ではない。作った当時の状態は 11-05 昼のコードを読んで書いた。「ある」は試験が通っている物で、人が使った確認は別に要る。

## 一周の形

```
① 仮説を見ながら、自分の考えを話す
② 作りながら、工夫を話す
③ できた物を上げ、工夫と考えをカメラか音声で残す
        ↓
他の人の作った物のギャラリーで見られる  ＋  型紙の版が直る  ＋  エンジンごと直る
```

前提は本人の言葉のまま: 「型紙が正解ではなくて、とりあえずAIが考えた仮説であるということを明示する。システム側もそれを認識した上でループを回す」。

## 今の実装でどこまでできるか

| 段 | ある | 作りかけ | まだ無い |
|---|---|---|---|
| ① 仮説を見て話す | 開いたらすぐ仮説の札が並ぶ（#266）。自分の仮説を字で残せる | 内カメラは鏡だけ（端末の中で映す。残さない） | 話した考えを残す口。声は今「質問」にしか使えない |
| ② 作りながら話す | 作りながら見る頁（手順を進める・止まった札）。声か字で聞くと手順だけ答え、聞いた言葉と止まった段が残る | 工夫の欄は字で記録の時に書く形（#266）。作る過程の動画から札を付ける道（#225。本人の動画待ち） | 作りながら工夫を声で残す口 |
| ③ 上げて残す | 手帖で写真と動画を上げる。撮影情報を落とす。感想と工夫の字。ギャラリーで見られる（#266） | 動画の札に「人の工夫」の種類（#225） | カメラか音声で工夫と考えを残す口 |
| 型紙の輪 | 記録 → 人の説明 → 人が寸法を 1 つ変えて次の版 → 次の人は直した版を刷る。鍵なしで回る。工夫の字は輪の担当へ渡る | Claude の読みと案は、偽の応答の試験だけ。本物の API は 0 回（U-05） | 話した考えと工夫を、輪の材料にまとめる所 |
| エンジンごと | 雛形の床と版、全玩具を刷る試験（手で直す時の支え） | 報告の形・検査・雛形と形ごとの集計・直しの行き先（paper-to-toy の枝 engine/intake。main に未） | サイトの記録をエンジンへ渡す橋。雛形全体に効く直しの案を作る担当。直した雛形を全玩具で確かめて人が採る輪 |

## 受け持ち

| 物 | 持つ担当 |
|---|---|
| 音声の取り込み（①②③の話す口、声を字にする所） | sub-voice（窓口が立てる） |
| エンジンごとの改善（橋・雛形全体の案・全玩具で確かめる輪） | sub-engloop（窓口が立てる） |
| 頁の順路、ギャラリー、③の上げる口の形、輪の前提の明示 | サイトの線（sub-site） |
| 概要とデモの中心にこの一周を置く | サイトの線とデモの担当 |

話した物が流れ込む先の形（サイトの線が用意し、sub-voice と合わせる）:

- 字になった考えと工夫は記録の欄に入れる。②の工夫は手順の番号を付けて、工作の様子にも残す。
- 字の床は今の記録と同じ（長さ・連絡先）。声そのものは残さない。

## 守る線との当たり（本人に決めてもらう点）

1. **カメラと声を残すか。** 今の決まりは「子どもの写真・声は扱わない」（spec の I2）で、動画は「顔や声が入った動画は、映像を頁に出さず、札の字だけで回してよい」（カード 20261105-115602）。内カメラは顔が映る。推し: 声は端末で字にして、字だけを残す。写真は作った物だけで、顔の映った映像はギャラリーに出さない。
2. **公開の場のギャラリー。** 今の #266 は、合言葉なしの場で人の書いた文と写真を出さない（文の中の名前は機械で落とせない。J-028）。本人の言葉は「ギャラリーで見れる」。推し: 人が確かめた物だけを公開の場に出す口を足す。持ち寄りの確認と同じ形にする。
3. **子どもが使う時。** 上の 2 つは成人の前提で書いた。子どもの場は同意の形を決めてから（research/31 の 4）。

## 順番の推し

1. #266（開いたらすぐ作る・ギャラリー・工夫の欄）を main に入れる。① と ③ の土台なので先。
2. sub-voice が話す口を足す。サイトの線は流れ込む先の欄を合わせる。
3. #225（作る過程の動画）を main に入れ、本人の動画で 1 周する。
4. sub-engloop が橋と雛形全体の輪を作る。engine/intake を paper-to-toy の main に入れるのが最初の一歩。

## 確かめていない事

- 人がこの一周を通した事。声の認識が工作の場の音で使えるか。
- 工夫の字で本当に型紙やエンジンが良くなるか。学習の効果と同じく、主張しない。
