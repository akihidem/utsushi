## 「アーティファクト」で何ができるか（作る側が Claude Code の Artifact の資料で確かめた事）

claude.ai に置くページで、iPhone の Claude のアプリやブラウザで開ける。ページに次の力を持たせられる。

| 力 | 中身 | この口での使い道 |
|---|---|---|
| sample | ページから Claude に聞く。見ている人の Claude で答えるので、utsushi の API の鍵は要らない | 手順の質問 |
| assets | 画像などを上げて置く。上げた物は Claude の側に置かれる | できた物の写真 |
| db | 共有の記録を置く。人ごとの私的な置き場もある | 上げた写真に添える短い記録 |
| user | 誰が見ているか（名前ではなく ID） | 誰が上げたかを ID で持つ |

制約: 見る人は claude.ai に入っている必要がある（招いた人か、同じ組織の人）。ページは手元の画面（127.0.0.1）にはつながらないので、手順と凡例はページに埋めて置く。

## 案

**推し: 「工作の手帖」アーティファクトを 1 つ作る（成人だけ、本人が招いた人だけ）**

1. 開くと玩具と仮説の紙を選ぶ（刷った紙の題と同じ名前。仮説の動き方は出さない）
2. 「困ったら聞く」: 手元の版と同じ線で答える。よくある言葉（谷折り・山折り・糊代・蛇腹・色の境・物差し）は埋めた説明から答え、ほかは sample で、その紙の組み方と凡例だけを渡して聞く。仕組み・どの仮説かの質問は答えない
3. 「できた物を上げる」: 写真 1〜3 枚と短い一言（何が起きたか。動いた・動かない・わからない）。上げた物は本人だけが見られる場所に置く（上げた人と本人だけ）
4. 持ち寄りとのつなぎ: 上げた物を、本人が見て選び、今の持ち寄りの床（同意・権利・確認・個人情報、F10）に通してから持ち寄りの場へ移す。アーティファクトから直接公開しない。repo にも直接は入れない（試行の記録として載せる時は本人が決める）

## 守る線（どの案でも）

- 予想が先（F9.prediction）。アーティファクトでも仮説の動き方は出さない
- 順位を付けない（J-025）。上げた物に点や票を付けない
- 子どもの写真・声は扱わない（今週は成人のみ）。顔が写った写真は本人が持ち寄りへ移す前に外す
- 答えは手順だけ。答えに仮説の名前や動き方が混ざったら出さない（手元の版と同じ出口の検査）
