# 06 型紙の初期値を出し直す

型紙の最初の版には、事前メモの寸法を出発点にした値が残っていた。それらを土台にしないと決めたので、絵の測定と紙面の制約から出し直した。

**事前メモとの関係**: 事前の値を見た後の作業なので、独立した導出ではない。同じ値になった所は「同じになった」と書く。虎の寸法は事前の値を使わず、これから同じ方法で出す。

## 新しく分かった事

- 扇の線が集まる中心は、筒の上端より筒の幅の 0.7 倍ほど上にあり、像の胸のあたりに見える。扇は筒の口に載っているのではなく、中心の軸のまわりに開いている形に見える【解釈】。Q1 の案 (c)「像の軸を通す形」を支える観察で、今の型紙の「台に帯を載せる」形とは違う。
- 絵は描き方の誇張を含むので、寸法の証拠にはならない。実物で確かめる。
