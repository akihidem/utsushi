## 全体の見立て

2 つとも「AI が作ったと分かる型」を避けるための**禁止と検査の一覧**が芯で、相手は売り込みの頁（hero・行動の釦・機能の列）である。hallmark は「主題を配って毎回違う頁にする」流れ、impeccable は「既にある頁を磨く・批評する」命令の束。utsushi の入口は売り込みでなく展示で、型を作り直す段でもないので、**流れ・主題配り・頁の型はどれも当たらない**。

効くのは 2 か所だけだった。(1) 両方が名指しする「生成物の定番の見た目」（クリーム色の紙・明朝の大見出し・土色の差し色）に、A′ が半分かかっている事の自覚。(2) 見た目の世界を変えない**細部の床**（細い字の読める濃さ、長い名前で崩れない組み、選んだ時の色）。impeccable 自身が「頼み（brief）が勝つ。決まった美意識は定番の警告より優先」と書いており、本人の向きを先に置くこの評価のやり方と食い違わない。

## 拾う・拾わない

| 考え（出所） | utsushi での判断 | 理由 |
|---|---|---|
| 定番の「クリーム＋明朝＋土色」を、頼まれていないのに選ばない（hallmark 65、impeccable new-work） | **拾う（A′ の地だけ）** | 本人は「白の背景」と言った。山種美術館の名も白い壁の例として挙がった。クリームは作る側の手癖で、本人の言葉に戻すだけ |
| 小さな字も読める濃さ（impeccable の床、contrast） | **拾う** | 作品の札・出典の行は読まれてこそ「歴史的価値」を支える。色の世界は変えず、明るさだけ動かす |
| 長い名前で崩れない（hallmark 50） | **拾う** | 持ち寄りで玩具が増える前提（19 で候補に残した事の続き） |
| 選んだ時の色を頁の色から作る（impeccable） | **拾う（小さく）** | 紙と墨、黒と金の世界を、触れた時まで保つ |
| 字に付けた矢印を外す（hallmark 63） | **候補** | 参照のルックブックに無い。外すと字だけの静かな誘いになる。本人の目で決める |
| 頼みが勝つ（impeccable の brief wins） | **やり方として拾う** | この評価の「本人の向きが先」と同じ |
| 主題を配る・頁の型を毎回変える（hallmark の流れ） | 拾わない | 入口の型は本人が見比べて決めた。毎回変える事は凍結と逆 |
| 見出しの前の札の禁止、番号の禁止 | 拾わない | 章立て・出品番号は展示の作法 |
| 字間の広い大文字の札の禁止 | 拾わない | A の再現の芯 |
| 自前で書体を配る（impeccable の「system の書体を表の顔にしない」） | 今は拾わない | 和文の書体は重く、外への依存が増える。A の Helvetica は参照のサンセリフの写し |
| 1 画面 80 語・hero に見出しと 1 文と釦（hallmark 58・44b） | 拾わない | 売り込みの頁の決まり。入口は展示の順路で、釦も 1 つ（玩具の頁へ）しかない |
| 検査の台本（sloplint・impeccable の検出器）を動かす | 拾わない | 入れない・動かさないと決めた。必要な項目は上の点検で手で当てた |
| 動きの指南（animate・delight・overdrive） | 拾わない | 動きは本人の頼み（J-024）の 3 つだけを、この Skill に依らず作った |

## 入れた物と候補（効く順。どれも小さく、世界観を変えない）

1〜5 は 2026-11-04 に `src/web/looks.py` へ入れた（色は WCAG の比を作る側が計算して 4.5 以上に合わせた。下の対応表）。6 は本人に聞いてから。試験は `tests/test_looks_motion.py`。

1. **［入れた］A′ の地を白に寄せる**（`#fcfcfa`。額と部分の紙は `#fffefc`、区切り線は `#ebe8e2`）: `body.tenji{background}` を `#f6f3ec` から、ごく僅かに温かい白（例 明るさ 98 前後・彩度 0.004 以下）へ。`.tj-work`・`.tj-detail figure div` の `#fbf9f4` は地より少し明るい紙として残すか、地と同じにして影だけで掛ける。`border-top:1px solid #e4ddcf` の線も同じ明るさの帯へ寄せる。明朝と茶の字は変えない（3 軸のうち 1 つ動かせば型から外れる、という hallmark の直し方の順に合う）
2. **［入れた］細い字の濃さを 4.5 へ**（A′ `#8b8172`→`#7a7164` 4.67、`#a59b8b`→`#7c7160` 4.66／C `#5f584c`→`#827968` 4.6、`#7d7463`→`#8a806e`／A `#777`→`#6d6d6d` 4.62）: `.tenji .switch .cap`・`.tj-note`・`.tj-room .chapter`・`.tj-detail figcaption`・`.tj-hall .en` の `#8b8172`/`#a59b8b` を一段濃く、`.zine .switch .cap` の `#5f584c` と `.zine .switch` の `#7d7463` を一段明るく、`.ab-end` の `#777` を一段濃く。色相は今のまま
3. **［入れた。長い名前の玩具での試験はまだ］長い名前の保険**: `.tj-room h2` に `overflow-wrap:break-word;min-width:0` を足す（`keep-all` は残し、溢れる時だけ折る）。`.zn-toy h2` にも同じ。`.spread`・`.zn-toy`・`.zn-grid`・`.lay` の `1fr` を `minmax(0,1fr)` に。試験に長い名前（例 20 字）の玩具で欄を越えない事を足す
4. **［入れた。下限 10px］A の小さな字の下限**: `.t` の `clamp(8px,…)` の下限を 9〜10px に（最大の 11px と比はそのまま）。参照の「小さい字」の印象は残る
5. **［入れた］選んだ時の色**: `body.taiban ::selection`（墨に薄灰）、`body.tenji ::selection`（墨に地より一段濃い白）、`body.zine ::selection`（黒地に金 `#c9a96a` の薄い面）
6. **［入れていない。本人に聞く］矢印を外す**: A の `予想を書いてひらく →` の `→` を取る（A′・C は既に矢印無し。3 案で揃う）。本人に聞いてから

## この評価で分からない事

- 濃さ・色相は CSS の値からの計算。入れた後に A′ をヘッドレスの写し（1440・390 の幅）で見たが、本物のスマホでは見ていない。A の `.t` の上に重なる図の上の字（`wide-*` の白い帯）の濃さは図次第で計れていない
- 「白」の加減は本人の目の物。山種美術館の実際の壁の色は確かめていない（作る側が持つ根拠は本人の「白の背景」の言葉だけ）
- 2 つの Skill の主張（AI の定番の見た目が集まる事・検査で減る事）は各 repo の説明で、作る側は確かめていない
- naka_1717 さんの投稿の本文は窓口の伝言で知っただけで、作る側は原文を見ていない
- 拾う・拾わないは作る側の判断で、本人の目はまだ通っていない
