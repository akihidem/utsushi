# 32 型紙を直した人をコントリビューターとして示す案（種の記録）

本人の言葉（2026-11-05、窓口を通して届いた）:

> ユーザーのフィードバックでどんどん型紙が改善していくので、コントリビューターとしてランキング作ったりすると面白そう

**事前メモとの関係**: 事前メモに、型紙を直した人を示す案は無い。この案はここで初めて記録した。比べた形と決める点は、書き手（Claude Code のセッション）がここで初めて書いた。

**この文書の範囲**: 種の記録と、比べる形の下書きまで。形（ランキングにするか、名を連ねるだけにするか、やらないか）は決めていない。決めるのは本人で、答えが来るまで作らない。引用の外は書き手の整理で、本人の言葉ではない。

## J-025 との関係（切り分け）

- [J-025](../decisions/J025-no-ranking.md)（順位を付けない）が止めているのは、**学ぶ人を、その結果や速さで並べる事**と、記録で仮説の順位が動く事である。動いた・動かないや、早く作れたかを成績にしない線
- この案は、**型紙を直した人（報告や工夫が型紙の次の版に採られた人）を示す事**で、学ぶ人の出来を測る軸とは別の軸である
- ただし、直した件数で並べれば数を競う形になり、[philosophy.md](../philosophy.md) の「欄は読む物で、数を競う物にしない」とぶつかりうる。だから形を決める時に、この線を一緒に見る【読み】

## 比べる形（下書き。推しは置かない）

| 形 | 中身 | 良い所 | 気になる所 |
|---|---|---|---|
| A 件数のランキング | 採られた直しの数で、直した人を並べる | 本人の言葉どおりで、面白さが伝わりやすい。続ける理由になりうる | 数を競う形になる。報告の多い人が上に来て、小さくても効いた直しが見えにくい。J-025 の外だと言い切るには本人の判断が要る |
| B 名を連ねる一覧（順なし） | 版ごとに「この版は、この人たちの工夫で直った」と連ねる。並びは採った順か五十音 | 誰が型紙を直したかが見え、競わない。改善の輪（U-45）の「直しが次の版に効いた」が見える | 面白さはランキングより弱い。名前の扱いは A と同じだけ要る |
| C 版の頁に直しの出所だけ | 人を出さず、「何件の報告から、どこを直したか」を版の頁に書く | 名前の問題が無い。今の決まり（W-04）のまま出せる | 人への感謝や張り合いにはならない。本人の言う「コントリビューター」には足りない |

## 決める事

1. **形**: A・B・C のどれか、またはやらないか（本人）
2. **名前の扱い**: 今の決まり W-04（[site-requirements](../site-requirements.md)、記録は人に結び付けず場面に結び付け、名前の欄を置かない）と、[J-021](../decisions/J021-contributions-form-students.md)（生徒は通し番号、公開は管理者の本人が決める）の上で、A・B なら次のどれにするか
   - 本人が名乗る時だけ、自分で決めた呼び名（ハンドル）を出す
   - 呼び名も出さず、通し番号で出す
   - 本名は出さない（今の線のまま）
3. **未成年**: 子どもの記録は今週は集めない（U-45 の本人の決定）。子どもの呼び名を出すなら、保護者の同意の形（U-03・U-04）が先に要る
4. **数える物**: 採られた直しを数えるのか、出した報告を数えるのか。採ったのは人（作る側か本人）なので、採る人の判断が順に入る事も記録する

## 閉じる条件

本人が形と名前の扱いを決めれば閉じる。作ると決まったら Issue を分ける。決まるまでは、この案で画面も記録の形も変えない。
