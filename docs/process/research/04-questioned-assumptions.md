# 04 今の仕様で一番疑わしい前提

事前の仕様を到達目標ではなく最低ラインとして扱い、前提を疑って代替案と比べるための課題の一覧。上ほど、外れた時の損が大きく、早く確かめられる。結果と変えた所は `decisions/` に残し、この表の状態を更新する。

**事前メモとの関係**: どの前提も事前メモから取った。疑う理由と代替案は、ここまでの調査と型紙の生成から Claude Code のセッションが立てた物で、まだ実験も実物での確認もしていない。

## あえて変えない所（理由つき）

| 変えない所 | 理由 |
|---|---|
| Claude に座標や SVG を書かせず、生成器が描く | 寸法の検査と出典の印を確実に守れる |
| 出典の印を PDF から読み直す検査 | 権利の条件に関わり、外すと失格の恐れがある |
| 結果の 3 値と、記録の根拠 ID | 成否を人が決める設計の芯 |
| 題材の 2 種 | 本人の決定 |
| 紙の輪を閉じる事 | 本人の要件 |
