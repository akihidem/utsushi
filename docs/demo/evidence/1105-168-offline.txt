# 網を切って 7 場面を書き出した記録（#168）
この機械では網の名前空間（unshare）が使えなかったので、外へ出る口を道具ごとに塞いだ。機械の網そのものを切ってはいない。
- Python（場面と子のサーバ）: 環境の proxy を行き止まりの手元の番号に向けた（手元の口だけ外す）
- Chrome: --host-resolver-rules で手元以外の名前を引けなくし、--log-net-log で要求の記録を取った
- 塞げている事の確かめ: Python から dl.ndl.go.jp へ → Connection refused

$ python -m demo.prepare --check
